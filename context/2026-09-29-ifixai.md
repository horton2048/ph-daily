## 是做什么的（如实复述，不评价）

iFixAi 面向已部署的 AI agent 做独立审计。官网描述的流程为连接 agent、建立模拟环境、执行模拟测试并生成报告，审查任务目标、权限、工作流、组织责任边界和证据可复现性。

## 解决什么问题（事实层面，不判断值不值得解）

- agent 可能出现幻觉、提示注入、超越授权、流程违规或跨用户数据泄露等行为。
- 常见基准主要测技术能力；iFixAi 将业务目标、权限、流程与证据纳入审计范围。
- 企业需要留存可复现的测试轨迹与报告，用于内部治理或合规工作。

## 怎么做的（技术原理/机制，事实层面）

- 接入方式：通过 MCP 从 Claude Code、Cursor、Windsurf、VS Code、Cline 等连接；或只读连接 GitHub 仓库读取 AGENTS.md。
- 流程分为连接、模拟环境、模拟执行、审计报告四步。
- 官网列出提示注入、策略违规检测、工具调用治理、审计轨迹、利益相关方冲突及框架映射等检查方向。
- 官网称代码和 prompts 留在用户侧；该隐私声明及其技术实现未独立审计。
