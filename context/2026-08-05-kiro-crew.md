## 是做什么的（如实复述，不评价）

Kiro Crew 是 Kiro 推出的**开源、持久化 agentic 开发工作空间**：一个长期运行的 agent 工作区，跑在你自己的硬件上（本机或远程），"记得上下文、经验教训、技能，跨会话持续，回来时接着上次的进度而不是冷启动"。PH 产品描述原文："Kiro Crew is a persistent workspace that remembers your context, lessons, and skills across sessions, so you come back to progress instead of a cold start. Build a crew of agents that work across the tools you already use, wrapped in purpose-built Apps for the jobs you repeat."

形态上它是一个 **Gateway + agent session** 架构（见"怎么做的"），用户可以选择从桌面 app（macOS/Linux）、web dashboard、CLI 使用，也可以接 Slack、Discord、Telegram、Teams、Webex、WeCom、WeChat 等消息渠道继续同一份工作。多步任务可无人值守跑完、定时任务按计划跑、心跳（heartbeats）监控系统直到需要人介入。另有"Apps"概念：把某个重复性工作封装成"专用界面 + agents + skills + 计划 + 集成 + 后端服务"的组合。

maker 在 PH 开场评论里称：Kiro Crew 起源于 Amazon 内部项目 MeshClaw，不到 6 个月积累 39,000+ 开发者、数百贡献者，现开源公开。

## 解决什么问题（事实层面，不判断值不值得解）

- **冷启动（cold start）**：AI 会话一关上下文就没了，每次都要重新交代背景。评论区用户 Vaishnavi Goel 原话："half my mornings with AI tools are still re-briefing yesterday's version of me"。
- **会话结束即任务终止**：README "Why Kiro Crew" 原话："Most agent sessions end when the chat closes. Kiro Crew runs continuously on hardware you control and keeps working between conversations."（大多数 agent 会话在聊天关闭时结束；Kiro Crew 在你控制的硬件上持续运行，会话间隙继续工作。）
- **重复性工作无人固化**：README 称反复出现的模式可沉淀为可复用 skills，不用每次重讲。
- **单一界面的局限**：需要在桌面/网页/CLI/消息 App 间无缝切换同一份工作（one Gateway, many surfaces）。

## 怎么做的（技术原理/机制，事实层面）

来源：GitHub KiroCrew README + kiro.dev/docs/crew + PH maker 评论

- **Gateway 架构**：Gateway 是常驻进程，把"agent 在哪跑"和"你在哪工作"分开。桌面 app、web dashboard、Slack/Telegram/WeCom、CLI 的请求都由 Gateway 路由到受管的 agent session；同一套 memory/tool/approval/policy 服务。dashboard 默认 `http://localhost:5476`，消息渠道是出站连接，无需对外暴露端口。
- **Agent session / ACP**：每个会话或后台任务对应一个 agent session，session provider 用 **kiro-cli** 驱动（ACP 协议，Agent Client Protocol），流式传输模型与工具事件。根据负载，session 由独立 ACP 进程或共享多路复用 ACP runtime 支撑。
- **持久化**：会话、memory、计划、任务 checkpoint 在 Gateway 重启后仍在；调度/被动任务不需要人守在终端。会话隔离（"an agent session is a logical isolation boundary"）。
- **自学习**：纠正与任务失败变成"durable lessons"（持久经验），改变后续行为；偏好与项目上下文按工作空间隔离。例子："no, always run the frontend checks before calling a change done" 会变成该工作空间的 lesson。
- **自进化**：重复模式自动合成可复用 skills，可查看/打磨/删除；memory、lessons、skills 都可见可编辑。
- **长任务与无人值守**：给任务 spec 后离开，它计划步骤、执行、验证、失败重试、checkpoint 续跑；可"只跑确定性脚本/命令不用模型调用"；定时（timezone-aware recurring jobs）、事件、认证 webhook 触发；heartbeats 监控。
- **并行子 agent（delegation）**："research these three options in parallel and recommend one" 会派出隔离子 agent 并把结果带回父会话。
- **Apps 与扩展**：可安装 Apps（dashboard 页面 + 作用域化 Gateway API + 事件 + 生命周期 hooks）；可加 MCP servers、markdown skills、hooks，不改核心 runtime。
- **安全纵深**：工具审批、OS 沙箱、敏感路径检查、凭证脱敏、deny 规则、审计事件、治理 profile（defense in depth）。
- **模型**：模型请求由 kiro-cli 处理，沿用你账户的模型配置。
- **技术栈**：Python（Apache-2.0）；版本 v0.1.x（最新 stable tag v0.1.3，2026-07 创建）；桌面端 macOS/Linux（Windows 暂无桌面版，可用源码安装跑 Gateway + 浏览器 dashboard）；Docker 镜像 ghcr.io/kirodotdev/kirocrew。

## 定价 / 商业模式

（kiro.dev/pricing，个人订阅档；Kiro Crew 本体开源免费，定价对应的是 Kiro 的模型/额度服务）

- **KIRO FREE**：$0/月，50 credits，开放权重模型 + Claude Sonnet 4.5。
- **KIRO PRO**：$20/人/月，1,000 credits，可加购 credits（$0.04/credit）。
- **KIRO PRO+**：$40/人/月，2,000 credits。
- **KIRO PRO MAX**：$100/人/月，5,000 credits。
- **KIRO POWER**：$200/人/月，10,000 credits。
- **Teams/Enterprise**：集中计费、SSO、用量分析、企业安全控制，联系销售；GovCloud 定价约高 20%、无 Free 档。
- **模型**：默认 "Auto"（多种前沿模型混合 + 专用模型/意图检测/缓存）；可选 Sonnet 4.5/4.6、Haiku 4.5、Opus 4.5/4.6/4.7；开放权重模型含 Qwen3 Coder Next、DeepSeek v3.2、MiniMax 2.1。
- **新人激励**：首次用社交登录或 AWS Builder ID 升级付费档送 $20 额度。
- **商业模式**（事实归纳）：开源工作空间（KiroCrew Apache-2.0）做获客，按模型使用收 credits 费；与 AWS（Builder ID、GovCloud、账单）深度绑定。
