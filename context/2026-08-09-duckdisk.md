## 是做什么的

表格优先的 macOS 存储分析器，一眼看到目录大小、分配空间、占父目录百分比、文件数和类型统计；支持本地盘、OneDrive、Google Drive 和 SSH 服务器，云盘只读元数据不下载，删除前先入待审清单。

## 痛点 / 机制 / 商业

- 痛点：圆图看出大块不知具体文件；本地/云盘/SSH 各装工具；误删无救。
- 机制：表格树直达文件级；一个 App 全扫本地+云盘+SSH；删除先进待审清单可撤。
- 商业：完全免费开源（AGPL-3.0），Mac App Store 与 GitHub Releases 双渠道。
