## 是做什么的（如实复述，不评价）

一个建筑量测与成本核算工作台，含一个名为 Onyx 的 AI agent 可代用户执行动作，全程在浏览器内。
把图纸到发票的工作流合并到一个平台，替代拼凑五个不同工具。宣传语："从蓝图到发票，无需拼凑五款工具。"

## 解决什么问题（事实层面，不判断值不值得解）

- 建筑 preworkflow 工具碎片：量测、估算、发票分属不同软件，需手动串联
- 现有选项二选一："2005 年的老软件"或"易出昂贵错误的 GPT 套壳"
- 建筑行业缺与其他行业相当的 AI 工具

## 怎么做的（技术原理/机制，事实层面）

工作流：
1. 上传图纸（施工蓝图）
2. AI 检测并勾勒房间
3. 校准比例尺
4. Onyx agent 自动量测算量
5. 量测数据转成本估算
6. 估算转开发票发送

Onyx agent 可"代用户执行动作"，跨管线自动化。maker 称把"数天变数小时或数分钟"。
用 Claude Code + Vercel + Next.js 构建，纯浏览器端。
