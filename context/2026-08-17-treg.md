## 是做什么的（如实复述，不评价）

一个工具 API 聚合平台，统一接入 2600+ API（SEO、社交、线索、广告、爬虫等），
一个 URL 和一个 token 即可调用。agent 按任务搜索工具，查看价格和评价。
0% 加价：按调用付费，不收中间商利润。开源。

## 解决什么问题（事实层面，不判断值不值得解）

- agent 需要调用多种工具 API，但每个 API 有独立的认证和计费
- 工具 API 分散，agent 难以发现和选择最佳工具
- 中间商加价增加使用成本

## 怎么做的（技术原理/机制，事实层面）

- 统一 API 网关：2600+ API 通过一个 URL 和一个 token 调用
- 按任务搜索：agent 描述任务，平台推荐合适工具
- 价格透明：查看每个 API 的调用价格
- 0% 加价：按调用成本原价收费，不收中间商利润
- 具体技术架构、开源协议未查到
