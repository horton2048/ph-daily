## 是做什么的（如实复述，不评价）

一个开源文档框架：把 Markdown/MDX 文件丢进文件夹，自动生成带导航、搜索、主题、SEO 的完整文档站，
无需 boilerplate。底层生成一个隐藏的 Astro 项目，需要完全控制时可用 `blume eject` 解出独立
Astro 项目。定位为 Mintlify / Fumadocs 的开源替代。

## 解决什么问题（事实层面，不判断值不值得解）

- 现有文档框架（Mintlify 等）要么闭源 SaaS 要么配置繁重
- AI 时代文档需要既给人读也给 agent 读，缺少开箱即用的 llms.txt / MCP 支持
- 内容源分散（本地文件、GitHub Releases、Notion、Sanity），缺统一接入层

## 怎么做的（技术原理/机制，事实层面）

- 基于 Astro + Vite，静态 HTML 输出；Tailwind v4 样式；TypeScript schema 校验配置
- 搜索默认 Orama，可选 FlexSearch / Pagefind / Algolia / Typesense，无需托管服务
- **AI-ready 机制**：自动生成 `llms.txt` / `llms-full.txt`、原始 Markdown URL、Copy as Markdown、
  可选 Ask AI 助手，以及一个 MCP server 供编码 agent 检索文档
- 组件在 MDX 中无需 import 即可用（卡片、tabs、accordion、代码组、文件树等）
- 内容源扩展：remote MDX、GitHub Releases、Notion、Sanity、自定义后端
- API 参考渲染（Scalar，OpenAPI/AsyncAPI）、导出 PDF/EPUB、i18n 本地化路由
- 部署适配 Vercel / Netlify / Cloudflare / Node
