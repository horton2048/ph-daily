## 是做什么的（如实复述，不评价）

Hexis 是"Git 之上的一层"（a layer on top of Git）：把公司的 AI skills、工具、知识/上下文定义为 Git 仓库里公司自己拥有的文件（纯 Markdown 与 YAML），集中管理、经 review、按文件做访问控制，再经 MCP 供任何 AI agent runtime 消费。

官网定义"四件事完整刻画一个 agent"：
- Context：带 provenance 的 typed knowledge nodes（每个事实标注来源、最后编辑人、验证时间），编译成可遍历、可批量更新、可建 dashboard 的图谱。
- Skills：纯 Markdown 写的过程，而不是埋在 config 里的 prompt 片段；拥有流程的人可读、diff 可审查、可移植到任何 runtime。
- Tools & permissions：工具 manifest + vault 中的密钥 + 访问规则（哪个 agent 可读哪个文件、可调哪个 endpoint），改动走 review。
- Identity：每个 agent 是带独立凭据和独立 scope 的具名 actor（非共享 service account），每个动作都可归因到它。

## 解决什么问题（事实层面，不判断值不值得解）

- 创始人评论（Ali Raza，5 天前，5 upvotes）：团队把 skills 和 context 放 GitHub，但 "GitHub was built for software development, and it breaks down when you use it at scale for something it wasn't built for"（GitHub 为软件开发而生，规模变大后用它做非本职会崩）。
- Hexis 保留 Git 的核心（versioning、PRs），补充：非开发者友好的 UX、文件级访问管理——后两者"用 GitHub/Gitlab 就是行不通"（"just doesn't work with Github/Gitlab"）。
- 官网核心论点："A company whose agents live inside a vendor's product doesn't own its agents."（agent 住在供应商产品里的公司并不拥有自己的 agent。）今天 context、tools、skills、permissions 都在供应商 harness 里，Bevel/Hexis 用公司自己拥有的文件取代之。
- 目标场景：企业级多 agent 部署的治理、可归因、权限管控。

## 怎么做的（技术原理/机制，事实层面）

- 仓库即 source of truth，示例目录：`your-company/` → `knowledge/`、`skills/`、`tools/`、`agents/`、`access/policy.yaml`。
- 格式纯 Markdown + YAML；branches、change requests、diffs 直接用 git 原生能力（"git's, not features we rebuilt"）。
- 支持的 agent runtimes：Claude Code (desktop)、Cursor (desktop)、ChatGPT (desktop)、opencode (desktop)、后台 agents (server-side)、in-platform agents（自托管模型）。接入描述为对现有员工工具 one-click，对无人值守/后台 agents 同一套 governed surface。
- 团队自研 UTCP（Universal Tool Calling Protocol，开源的 MCP 替代方案，获 AWS、Adobe、Royal Bank of Canada、MuleSoft 工程师背书）：Bevel 每个能力以纯 HTTP endpoint 暴露，无中间 proxy server。
- CodeMode：其"通过代码执行而非一次一调做 tool-chaining"的库（官方统计：stars 1.5k+、downloads 45k+），团队自称"first ever library for Code Mode (Code Execution for Tool Calling)"。
- UTCP GitHub 生态（org universal-tool-calling-protocol）：code-mode(~1,500★, TS)、python-utcp(644★)、utcp-specification(302★)、utcp-mcp(201★)、go-utcp(120★)、typescript-utcp(117★)、rs-utcp(57★)、utcp-agent(50★)。规格最近更新约 2 小时前。
- 官网公告：核心将于 2026-08-08（发布当天）开源。
