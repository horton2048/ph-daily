## 是做什么的（如实复述，不评价）

Crew 是一个 macOS 上的 Claude Code companion。它给每个 Claude Code chat 和 subagent 分配一个像素小怪物，沿屏幕底部走动：thinking、running tool、waiting on you、done、failed 等状态会用动作表现出来。用户看一眼屏幕底部，就能知道多个 Claude Code 会话是否在工作、卡住、等待权限或已经完成。

Pro 功能还包括点击小怪物跳转到对应 terminal session、在浮层里批准命令、dashboard 显示 tokens/cost/per-project stats、天气和 git/test reactions、配饰等。

## 解决什么问题（事实层面，不判断值不值得解）

- Maker Ravindra Sisodia 在 PH 自述：自己经常同时开四五个 Claude Code chats，但看 spinner 不知道哪个在思考、哪个等自己、哪个十分钟前已结束。
- Crew 把 agent 状态变成 peripheral read，减少用户为了检查状态在窗口之间 alt-tab。
- 当命令需要权限时，Pro 中小怪物会举起 command 和 Allow/Deny，用户可直接批准，而不用去找 terminal 窗口。
- 它针对的是本地多 Claude Code session 的可见性和注意力管理，不是 coding agent 本身。

## 怎么做的（技术原理/机制，事实层面）

- macOS app：官网写 macOS 13+，Apple Silicon & Intel，works with Claude Code。
- Hook 集成：maker 自述点击 Connect 后会自动接入 Claude Code hooks，保留已有 hooks 并做 backup。
- 本地状态：公开资料称 nothing leaves your Mac，无账号、无网络请求、无 telemetry；通过 Claude Code hooks 写在 `/tmp` 的 local marker files 读取状态。
- 视觉表现：每个 chat hash 到 10 个物种之一并在 session 中保持；subagents 在 parent 后方像小队一样跟随。
- 实现：maker 自述 solo 用 Swift 和 Claude Code 在几周晚间时间构建；六个/十个 species 为代码中逐像素绘制。

## 定价 / 商业模式

官网定价：Crew Free，$0，free forever，包含每个 chat/subagent 一个 creature、live states、squads、tool props、hover-to-inspect cards、one display、fully local。Crew Pro $12 once，一次性 lifetime updates，包含 tap-to-jump、playtime、dashboard、weather/git/test reactions、accessories、all monitors、launch at login 等。PH maker 说明当前能看到的免费能力之后不会被拿走。

## 关联信息 / 生态

- 与 Conductor/Superset 这类多 agent 编排不同，Crew 不负责编排 agent，只负责把本地 Claude Code sessions 的状态可视化。
- 与 statusline 或 terminal notification 相比，Crew 走 ambient UI / desktop pet 形态，把状态长期放在屏幕底部。
- 相关产品包括 Masko Code、AgentManager、Claude Code hooks、Conductor、Superset。
