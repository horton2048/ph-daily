## 是做什么的（如实复述，不评价）

让用户构建并部署通过 iMessage 和 FaceTime 运行的对话式 AI agent。FaceTime 视频 agent 能看到
用户给摄像头看的内容并实时响应。支持客服、线索捕获、远程支持、远程医疗 intake、引导式 onboarding
等场景。部署视频 agent 只需几行代码。

## 解决什么问题（事实层面，不判断值不值得解）

- 创始人论点："今天出货的每个 voice agent 都是盲的，只能处理客户能口述的内容"
- 视觉问题（身份验证、远程指导、物品识别）需要视频，voice-only agent 无法处理
- 视频通话通道（WhatsApp/FaceTime）尚未被 agent 化，缺开发者层 API

## 怎么做的（技术原理/机制，事实层面）

- 用户配置 system prompt 和 tone 创建对话 agent，支持 inbound / outbound 工作流
- 视频部署：几行代码即可上线一个 FaceTime agent
- CRM 集成：HubSpot、Close、GoHighLevel 同步对话历史
- 隐私：加密用户信息，不暴露
- 现场演示：可直接 FaceTime +1 310 279 2297 体验
