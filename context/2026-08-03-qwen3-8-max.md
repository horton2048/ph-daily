## 是做什么的（如实复述，不评价）

Qwen3.8 是阿里巴巴 2026-08-03 发布的新一代基座大模型，总参数量 2.4 万亿（2.4T）。其中最大尺寸的 Qwen3.8-Max 是千问系列迄今尺寸最大、性能最强的旗舰模型，在编程（Coding）与专业办公（Cowork）方面能力大幅提升。模型采用稀疏 MoE 架构，单次激活约 950 亿参数，支持最长 100 万 Token 上下文窗口，原生集成多模态视觉理解。

模型主打自主编程突破：程序员只需一句话指令，模型可从空文件夹出发、自主运行多日完成真实项目交付（自我进化式开发）。

## 解决什么问题（事实层面，不判断值不值得解）

- 面向编码与 Agent 长程任务，从"会写代码"走向"能交付任务"（让模型可长期托付、无需人工盯守）。
- 以"旗舰能力、中端价格"切入，性价比对标 Claude Opus 5 / GPT 中端模型。
- 首个开放权重的 Max 级旗舰模型，服务开源生态与私有化部署。
- 专业办公（Cowork）场景：千问办公（QwenWork）同日开启公测并内置 Qwen3.8-Max。

## 怎么做的（技术原理/机制，事实层面）

- 架构：第三代稀疏 MoE + 混合注意力机制联合优化；总参 2.4T、激活 95B。
- 上下文 1M Tokens；多模态视觉理解原生集成。
- 自主编程机制：模型持续运行（如 16 天），通过执行结果与外部反馈修正计划，管理 issue/开发/测试/预览/日志反馈循环；人类工程师可通过钉钉追加要求。
- 自我进化式开发案例（据技术报告）：从零构建 oh-my-cli（截至 2026-07-30 约 16 天、265 次提交、127 个 PR、151 个 issue）；复现论文约 125 小时、7600 行代码、1100+ 步、33 轮 GPU 训练，AIME24 提升 2.7 分；多模态电商挑战赛 24 小时独立完成 45 次提交。
- 兼容 OpenAI 等其他平台接口，用户可调推理深度与成本。
- 已知基准（厂商/第三方声称）：Arena 全球第二（得分 1496）；CodeArena 全球第四；Vision Arena 第二梯队；PaperBench 93.0（较上代 +28.2）；WideSearch 81.9；Agent's Last Exam 52.4；IF Bench 82.8；GPQA Diamond 92.6；BabyVision 82.0；OSWorld-Verified 86.1（榜首）。

## 定价 / 商业模式

API 按量计费 + 开源权重双轨：

- 国内：每百万 tokens 输入 12 元、输出 36 元、隐式缓存命中 1.5 元。
- 国际：输入 $2/百万 tokens、输出 $6/百万 tokens、隐式缓存 $0.25/百万 tokens（报道称输入/输出价格约为 Claude Opus 5 的 40% 与 24%）。
- 开源：Qwen3.8-Max 与 Qwen3.8-27B 权重计划于发布后约一周在 HuggingFace 与 ModelScope 上线（首个开放权重的 Max 级模型）。
