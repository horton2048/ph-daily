## 是做什么的（如实复述，不评价）

Aloud 让用户在 Mac 上**说出对代码/产品的反馈**，系统把语音 + 屏幕录制 + 实时转录**整理成可执行的任务**（task），一键推送给编码智能体（如 Cursor、Claude Code、Cline 等）去跑。

换句话说：把"口头反馈"翻译成"AI 编码智能体能执行的指令"，省去手动打字写 issue/task。

## 解决什么问题（事实层面，不判断值不值得解）

- 设计师/PM 对开发有反馈时，写文字很费时；当面说给工程师听，工程师又要重写一遍成可执行任务
- 屏幕演示 + 口头说明是表达产品反馈最自然的方式，但目前没有工具能直接把"嘴说 + 屏幕"转成 AI 可执行的任务
- "开会时说了一堆 issue，会后没人记得"是产品团队的常见痛点

## 怎么做的（技术原理/机制，事实层面）

- 捕获：录音 + 屏幕录制 + 实时转录
- 整理：用 AI 把口语化反馈整理成结构化任务（带优先级、所属模块、对应文件）
- 推送：把任务推给编码智能体执行（具体推送协议本次未抓到——可能是 MCP / API / 自定义协议）
- 形态：Mac 应用（PH 标签 Mac · Developer Tools）
