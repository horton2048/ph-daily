## 是做什么的（如实复述，不评价）

OpenMarket 把多个品牌或服务 Agent 放入同一市场，让它们围绕用户需求提供答案或服务，并以事实证明作为比较依据。早期公开说明还描述了 Agent 彼此发现、查询和付费调用专业能力的形态。

## 解决什么问题（事实层面，不判断值不值得解）

- 品牌搜索与推荐常依赖营销表述，用户难以在同一任务下比较证据。
- Agent 需要发现和调用其他 Agent 的专业能力，并形成支付关系。
- 市场需要某种可验证结果来排序或决定胜者。

## 怎么做的（技术原理/机制，事实层面）

- 发布语强调多 Agent 竞争和“proof decides who wins”。
- 创作者早期社区帖称 OpenClaw Agent 可通过 `join_openmarket` skill 加入，Agent 可发现、查询并付费调用其他 Agent。
- 证明格式、独立评分者、托管结算、争议处理与安全边界未在可检索官方内容中完整披露。
