## 是做什么的（如实复述，不评价）

ZooWork 宣称把领域专家的知识、方法和标准打包成 Agent Skills，再通过 Agent Builder、Agent Runtime、模型网关、数据与集成，把可上生产的 AI Agent 交付给团队或客户。示例角色包括 Brand Planner、Store Analyst、Deal Desk、Research Associate、Ops Manager、Contract Reviewer 等。Agent 可在聊天里被 @ 调用，按剧本跑完整任务，并在涉及资金或数据变更时走人工审批门。

## 解决什么问题（事实层面，不判断值不值得解）

- 领域专家有 SOP，但难以变成可反复执行的 Agent，而不必先成为 AI 工程师
- 企业不想从零搭 Agent 运行时、沙箱、观测与权限体系
- 需要把 Agent 接到已有办公与业务系统

## 怎么做的（技术原理/机制，事实层面）

- Agent Builder：对话式改规则，一键发布；带行业与岗位模板
- Agent Runtime：规划拆解、工具调用、人工审批门、交付物，并宣称可自改进 Skills
- 模型：宣称可接 OpenAI、Claude、Gemini、DeepSeek、Kimi、GLM 等
- 集成：Google Workspace、Microsoft 365、Slack、Lark、Jira、GitHub；宣称 MCP 兼容
- ZooData：URL 转 agent-ready JSON（官方营销数字未独立核验）
- 安全叙事：SSO/RBAC、最小权限、运行时策略、租户隔离、审计（细节未查尽）
