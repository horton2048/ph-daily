## 是做什么的（如实复述，不评价）

Freebuff 是一个完全免费的 AI 编码 Agent，提供 CLI、桌面端（Mac/Windows/Linux）、Web App 构建器和云端 Agent 四种形态。它不收订阅费、不需要用户自带 API Key，直接给用户接入多个开源/第三方大模型来完成编码任务，定位为 Claude Code、Cursor、Codex、Replit、Devin、Lovable、Bolt、Windsurf 等付费编码工具的免费替代品。

## 解决什么问题（事实层面，不判断值不值得解）

- 主流编码 Agent（Claude Code、Cursor、Devin 等）普遍是订阅制或按 token 计费，对个人开发者/学生存在成本门槛
- 用户往往需要同时订阅多个工具、管理多个 API Key 才能使用不同模型
- 团队指出：过去一两年模型推理成本大幅下降，但主流付费编码工具的定价并未同步下降

## 怎么做的（技术原理/机制，事实层面）

- 通过广告收入补贴模型调用成本，从而对用户完全免费（无订阅、无 API Key）
- 接入多个开源/低成本大模型：DeepSeek v4（Pro）、MiMo 2.5 Pro、GLM 5.2、MiniMax M3，另用 Gemini 3.1 Flash Lite 做文件查找（file finding）；官网也提及 GPT 5.6 Luna 等模型
- 使用限额：默认每天 6 次会话、每次会话时长 1 小时；部分模型（如 Flash 系列）会话数不限
- GitHub 仓库 CodebuffAI/freebuff 公开可见（未确认具体开源协议）

## 定价 / 商业模式

完全免费，无订阅制、无需用户提供自己的 API Key。商业模式是广告变现（官方称与 Carbon Ads 等广告网络合作补贴模型调用成本），用免费模型使用权换取广告曝光/点击收入，而非向终端开发者收费。

## 关联信息 / 生态

- 出自 Codebuff（YC F24）团队，Codebuff 本身是一个 CLI 编码 Agent 产品，Freebuff 是其"完全免费"路线的新产品线
- 创始人 James Grugett 此前创立 Manifold Markets，一个拥有 15 万+ 用户创建预测市场、月访问量达数百万的预测市场平台
- 直接对标/竞品：Claude Code、Cursor、Codex、Replit、Devin、Lovable、Bolt、Windsurf
