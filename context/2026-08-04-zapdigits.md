## 是做什么的（如实复述，不评价）

ZapDigits MCP 是一个 MCP 服务器，将 Claude 和 ChatGPT 等 AI 助手连接到 Google Analytics、Google Search Console、Meta（Facebook）广告以及 30 多个营销数据源。用户可以在 AI 助手中直接用自然语言查询营销数据、生成报告、提炼洞察（官方主页定位"Ask your marketing data anything"——询问问题、生成报告、挖掘洞察）。它是 ZapDigits 营销报告平台的 AI/MCP 能力延伸：ZapDigits 本身是一个面向营销代理机构的白标仪表盘/客户报告工具，统一整合 30+ 数据源。

## 解决什么问题（事实层面，不判断值不值得解）

- 解决营销数据分散在多平台、需频繁切换工具的问题：ZapDigits 统一 30+ 数据源（GA、Search Console、Meta 广告等）。
- 解决在 AI 助手中访问营销数据的问题：通过 MCP 服务器把 Claude / ChatGPT 直接连接到这些营销数据源。
- 解决代理商客户报告耗时问题：官方称"每周节省数小时"，支持拖拽布局、白标品牌定制、数据源无代码连接。
- 解决按用量计费不可预测的问题：ZapDigits 主打"加更多客户、价格不变"，定价可预测，对比 AgencyAnalytics / Databox 等竞品。

## 怎么做的（技术原理/机制，事实层面）

- MCP 机制：作为 Model Context Protocol 服务器运行，向 Claude / ChatGPT 暴露营销数据查询工具（问问题、生成报告、挖掘洞察）。
- 数据源整合：连接 Google Analytics、Google Search Console、Meta 广告及 30+ 营销数据源。
- 底层平台：基于 ZapDigits 白标报告平台，支持拖拽布局、widget 库、按客户/活动保存视图、上传自有数据集、API/复杂数据集。
- 无代码接入：官方强调"连接数据源无需代码"。
- 托管与合规：欧盟托管（Made in EU），宣称 GDPR 合规；官方列有安全政策与 security policy 页面。
- 具体 MCP 实现语言/协议细节未查到。
