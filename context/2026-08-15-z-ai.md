## 是做什么的（如实复述，不评价）

GLM-5.3 是智谱 AI（Z.ai）于 2026-08-14 发布的编程大模型，针对复杂、长周期编码任务优化。
不同于常规迭代重新预训练基座模型，GLM-5.3 在 GLM-5.2 同一基座上通过大规模扩展后训练
（post-training）实现能力跃升，官方称是当前最强的开源权重编码模型。产品已接入 GLM
Coding Plan、ZCode，并兼容 Claude Code、OpenCode 等编码 agent 工具。

## 解决什么问题（事实层面，不判断值不值得解）

- 复杂、长周期（long-horizon）编码任务对模型的稳定性和 token 效率要求高
- 开源权重编码模型此前普遍落后于闭源旗舰（Opus、GPT 系列）
- 目标场景：接入 Claude Code / OpenCode / ZCode 等编码 agent 作为底层模型

## 怎么做的（技术原理/机制，事实层面）

- 743B 参数，基座沿用 GLM-5.2，不重新预训练，仅扩大后训练规模
- 官方 Code Bench 评测（自研）：High 推理档 31.4% 准确率，超过 Claude Opus 4.8 的 29.5%
- 效率优势：完成同等任务平均输出约 5 万 token，Opus 4.8 约需 12 万 token（官方称）
- 在 Terminal Bench 3.0、Agents' Last Exam (CLI) 等公开基准上，官方称列开源模型第一
- 网络安全能力：CyberGym 成功率 84.5%（官方称超 Anthropic Mythos 83.8%、GPT-5.6 Sol 83.6%）；
  但 ExploitBench 落后对手（54.4% vs Mythos 78%、GPT-5.6 Sol 76.5%）
- 团队负责人 Zac Zuo 在 PH 评论区提到 GLM-5.2 此前已被 Hugging Face 用于基础设施入侵调查
- 开源信号明确（PH 品类标 Open Source，团队提及 MIT 许可证），已查：权重尚未发布到
  Hugging Face（GLM-5.2/5.1 已有仓库 zai-org/GLM-5.2、zai-org/GLM-5.1），GLM-5.3 仓库
  预计安全评估完成后（约两周，即 2026 年 8 月底）上线

## 定价 / 商业模式

通过 GLM Coding Plan 订阅制接入，三档：$18/月、$72/月、$160/月（年付分别为 $12.60、
$50.40、$112 每月）。Z.ai 尚未公布 GLM-5.3 的独立按 token API 价格。权重开源后预计可
本地部署/自托管（免费），但暂未发布。
