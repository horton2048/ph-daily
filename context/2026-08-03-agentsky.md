## 是做什么的（如实复述，不评价）

AgentSky 定位为"托管代理即服务"（managed agent as a service）。据 PH 榜单介绍，用户可"只需一键即可启动一个长效的人工智能代理"——无论是 Claude Code、Codex、Hermes 还是 OpenClaw。代理在云端按需运行，用户可随时查看完整历史记录、管理恢复功能，并通过 WhatsApp、iMessage、Telegram、Slack、网页、API 开发者接口和命令行界面进行访问。

其 tagline 强调"任何 harness、任何 LLM"，即代理的运行时框架（harness）和底层大模型都可以灵活选择。

## 解决什么问题（事实层面，不判断值不值得解）

- 解决用户需自行部署、运行和维护 AI 编码/个人代理（如 Claude Code、Codex、OpenClaw）的门槛。
- 让代理脱离用户本机，"离开笔记本"后台运行，实现持久化（长效）代理。
- 通过消息平台（WhatsApp / Telegram / Slack / iMessage）让用户随时随地与代理交互，无需专用客户端。
- 提供统一入口（网页 / API / CLI），可嵌入开发者工作流。

## 怎么做的（技术原理/机制，事实层面）

- 云端托管、按需（on demand）启动代理实例。
- 兼容多种代理框架/harness（Claude Code、Codex、Hermes、OpenClaw 等）与多种 LLM。
- 支持完整会话历史记录查看与"恢复"（resume）管理。
- 多渠道接入：WhatsApp、iMessage、Telegram、Slack、Web、API、CLI。
- 具体后端基础设施、隔离机制、计费细则：未查到。
