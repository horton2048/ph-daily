## 是做什么的（如实复述，不评价）

SHIUI 是一个以日本 Hinomaru（日の丸）海报为灵感的扁平墨水风 Web UI 组件库。官方文案写作 "Flat ink interfaces in the spirit of Hinomaru posters."，品牌署名 "SHIUI Press"，标注地点 "Kyoto — Tokyo"（属于品牌叙事文案，作者本人地理归属见下）。

形态上是一套可在浏览器里交互预览的 React/Next.js 组件集：

- **设计 Token 三件套**：「Paper. Ink. Sun.」——和纸底 #e5e3dc、墨 #2a2926、朱红 #e14d2a，零阴影，1.5px 描边，全套只用这 3 个色。
- **111 个 live 组件**：分 10 大类，按 №001–111 编号，包括 Buttons & Actions、Seals/Tags/Eyebrows（含 HankoSeal、HankoRound 这种"印章式"组件）、Forms & Inputs、Navigation、Feedback & State、Data & Walls、Overlays、Cards & Promo、Marks & Motion、Charts & Diagrams。
- **24 个 Block（完整页面区块）**：Block 01 Hero · 02 Type specimen · 03 Features · 04 Editions（3 档定价） · 05 Voices · 06 Questions · 07 Proof numbers · 08 First pressing list · 10 Collector login · 11 Checkout · 12 Printer · 13 Process · 14 Stock ledger · 16 Tonight only · 17 Closing argument · 18 Write us · 19 Signals · 20 Press desk · 21 Checkout steps · 20 Seal wall · 23 Ink trend · 24 Edition shares（注：源文档跳号 09/15，且 "20" 出现两次，疑似作者原文笔误，原样保留）。
- **每个组件可交互**：页面文案说明 "Try it on the card, then copy import or source"，意味着用户在卡片里点击按钮、可直接复制 React import 路径或完整源码。
- **品牌印记**：Logo 是日丸 + "Shiui" 字样；命名大量借自版画/印刷术语（HankoSeal = 印章、KickerLabel = 眉头小字、Editions = 限量版、TicketStub = 票根、CouponEdge = 切角券、MarqueeStrip = 跑马灯条），整体是把"日式印刷物"作为隐喻贯穿到组件命名层。

## 解决什么问题（事实层面，不判断值不值得解）

- **现有 Web UI 套件的视觉同质化**：市面主流 UI Kit（Tailwind、Flowbite、Radix、HeroUI 等）多以中性灰 + 圆角阴影为主，作者意图提供一个"非主流审美"的、可整站直接套用的视觉系统。
- **日本文化语境产品的视觉资产缺口**：出海日本、或做和食 / 茶道 / 工艺品 / 文创电商等品类时，常见做法是贴和风图素材；SHIUI 提供"从 token 到组件"的系统化方案。
- **设计 token 与字体一并打包**：作者把 Shippori Mincho（标题）+ Zen Kaku Gothic（正文）+ Plex Mono（代码）三套字体与 3 色 token 绑定，省去使用者自己挑选配对的步骤。

## 怎么做的（技术原理/机制，事实层面）

- **技术栈**：从作者 ddark.dev 个人站自述的日常栈（React / Next / Astro / TypeScript，GSAP / Lenis / SVG / Canvas）以及站点 `src/components/blocks/` 的目录语义来看，SHIUI 是用 **React + Next.js + TypeScript** 构建的，部署在 **Vercel**。是否使用 Tailwind 未在页面明示，但大量类似 Kit 会基于 Tailwind，作者本人也熟悉 Tailwind 生态（PH 在 "similar products" 里把 Tailwind CSS 列为相似项之一）。
- **设计 Token 抽象**：3 色硬约束（Paper / Sumi / Shu），1.5px 线条、零阴影；展示页 `#tokens` 锚点列出每一色的用途说明（GROUND/WASHI/MARGIN、LINE/TYPE/FRAME、SUN/SEAL/SIGNAL），鼓励 "One accent, spent sparingly — sun, seal, shout."。
- **组件实现**：111 个组件按 № 编号，每张卡片是一个 live preview + 复制 import/source 的入口；类别划分借鉴 Material/Tailwind 套件，但命名风格本地化（HankoSeal / KickerLabel / MarqueeStrip / CouponEdge）。
- **字体锁定**：标题 Shippori Mincho（衬线、明朝体）、正文 Zen Kaku Gothic（无衬线、角黑）、代码 Plex Mono，全部开源可商用（Zen Kaku Gothic / Shippori Mincho 均 OFL 字体，Plex Mono OFL）。
- **零阴影 + 1.5px 线**：整套组件只用 3 色 + 1.5px 实线边框，不使用任何 box-shadow / gradient，是视觉风格成立的硬约束。
