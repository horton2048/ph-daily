## 是做什么的（如实复述，不评价）

Capptivo 是一个**免费、开源（MIT）的屏幕录制 + demo 编辑器**，定位为 Screen Studio / Cursorful 的开源替代。本地优先（无需账号、无需订阅），跨平台支持 macOS 13.0+、Windows 10 (1903+)、Linux (PipeWire 1.0+)。录制屏幕后可在编辑器里加跟随光标的缩放、点击自动缩放、手绘标注、设备框、背景预设、字幕（本地 whisper.cpp 生成），并多尺寸导出（宽屏/方形/竖屏 9:16）。当前版本 1.0.2。

## 解决什么问题（事实层面，不判断值不值得解）

- **Screen Studio / Cursorful 收费且闭源**：想做精致 demo 但不想付费、不想被锁在闭源工具里。Capptivo 免费 + MIT 开源。
- **录屏后剪辑耗时**：从录制到出片要手动加缩放、标注、字幕。Capptivo 用跟随光标自动缩放 + 点击触发缩放 + 本地字幕生成，减少后期。
- **云端字幕/处理的隐私顾虑**：字幕用本地 whisper.cpp 跑，不上云。
- **目标场景**：开发者做产品 demo、发社交短视频、教程录制。

## 怎么做的（技术原理/机制，事实层面）

来源：官网 + GitHub README + PH 产品页

- **技术栈**：Tauri（跨平台桌面框架）+ Rust（后端：采集、编码、存储）+ React/TypeScript（前端 UI）+ FFmpeg（视频编码处理）+ whisper.cpp（本地语音转字幕）。
- **录制**：全屏/窗口/区域采集、摄像头画中画、麦克风 + 系统音频、录制中标注（笔/高亮/形状/文字/橡皮）、暂停/继续、全局热键 ⌥⇧R。
- **缩放与运动**：跟随光标缩放、点击自动建议缩放、固定缩放区域、缓动控制、时间线上拖拽缩放片段（中间动作自动补帧）。
- **光标**：多种样式（macOS / Tahoe / Minimal）、动态模糊、点击弹跳、摆动。
- **标注**：录制时实时绘制，保存为录制层之上的图层。
- **字幕**：本地 whisper.cpp 做语音转文字，烧录进导出画面；9:16 竖屏字幕按目标宽高比布局，不会被裁切。
- **导出**：MP4 / WebM / GIF，可选分辨率/帧率/质量；多尺寸（宽屏/方形/竖屏）一次编辑多格式出。
- **本地优先**：项目存 OS app-data 目录，无账号。
- **未签名**：当前构建未签名（Apple Developer 账号问题处理中），MDM 管理的 macOS 机器会有安装障碍。
