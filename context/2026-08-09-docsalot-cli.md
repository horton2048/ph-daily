## 是做什么的

面向 AI 编码 agent 的 CLI + 托管平台，让 Claude Code 或 Codex 用自然语言新建、拉取、更新文档并发布成精美站点。提供 hosted MCP、llms.txt、skill.md 让 agent 原生可调用，底层仍保留真实 CLI 供开发者接 CI。

## 痛点 / 机制 / 商业

- 痛点：Claude/Codex 生成的文档初稿散落在对话里，难统一发布；产品更新文档就过期。
- 机制：agent 原生可调用（MCP+skill.md+llms.txt）让文档变成 AI 检索的第一手数据源。
- 商业：SaaS 订阅制无免费档；Startup $39/月、Team $99/月、Enterprise 联系销售。
