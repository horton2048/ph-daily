## 是做什么的（如实复述，不评价）

Omarchy 是一套面向桌面用户的 Arch Linux 发行版和预配置环境。它组合 Arch、Hyprland 平铺窗口管理器与 Quickshell 桌面构建工具，并预装终端、编辑器、浏览器、办公、视频和录制软件。用户可以通过配置、主题和脚本调整系统，项目把这种可修改性与 agent 驱动的工作方式放在核心叙事中。

## 解决什么问题（事实层面，不判断值不值得解）

- 想使用 Linux 桌面但不想逐项选择窗口管理器、主题、终端和常用应用。
- 需要可通过配置文件、命令和脚本持续改造的工作环境。
- 目标用户包括开发者、终端重度用户以及希望运行本地 agent 工具的人。

## 怎么做的（技术原理/机制，事实层面）

- 底层发行版为 Arch Linux；桌面层采用 Hyprland，外壳/面板等使用 Quickshell。
- 手册列出 Neovim、Chromium、Obsidian、LibreOffice、Kdenlive、OBS Studio、终端工具和游戏等预装或可选应用。
- 仓库包含 `agents/skills`、`shell`、`themes`、`install`、`migrations` 等目录，并通过脚本管理安装、升级、主题和系统快照。
- 官网提供 ISO 下载、Manual、插件市场和 GitHub 源码；手册另列 Mac support、双启动和无人值守安装。
