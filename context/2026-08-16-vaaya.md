## 是做什么的（如实复述，不评价）

基于开发者的 GitHub 活动生成 agentic credit score，据此授信一条信用额度，让 AI agent 可
花在 1400+ 外部 API 端点上。提供基于 x402 支付协议的 managed agentic wallet，一次 MCP
安装即可接入 Exa、Firecrawl、Fal、Apollo.io、Browserbase、Modal 等服务。免预充值。

## 解决什么问题（事实层面，不判断值不值得解）

- agent 调用付费 API 需要人预充值钱包，门槛高、体验差
- 开发者探索 agentic commerce 不愿前期投入资金
- 多个 API 各自计费 / 接入，缺统一支付与身份层

## 怎么做的（技术原理/机制，事实层面）

- 评估 GitHub profile 构建"agentic credit profile"，据此授信额度
- agent 可串行 / 并行链式多工具调用；创始人演示用 Fable + Remotion 生成图形，支付由 Vaaya 处理
- x402 支付协议托管钱包，一次 MCP 安装接 1400+ 端点
- 安装：`npx @vaaya/mcp install`
- 用例：抓取社交平台做品牌/竞品情报、生成网站素材
