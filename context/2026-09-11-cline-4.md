## 是做什么的（如实复述，不评价）

把原本依赖 VS Code / JetBrains IDE 才能跑的 Cline agent，搬到一个独立桌面应用里：不用开编辑器，直接打开 Cline Desktop，指到 workspace，agent 就能读、改、跑代码。

桌面版的差异化在"跨形态无缝"——CLI / VS Code 扩展 / Desktop 里跑的 session 历史统一在一个列表里，可以从 CLI 起的任务在 Desktop 里接着干，反之亦然。可以从 Claude Code / Codex 把任务和上下文导入到 Cline 里继续。

底层复用同一套 Cline agent harness（"optimized for open-weight models"），所以同一段对话既能跑 Claude/GPT/Gemini 闭源模型，也能跑 GLM/Kimi/DeepSeek/Qwen 等开源权重模型（通过 ClinePass 或 BYOK 走 Ollama/LM Studio 本地端点）。

## 解决什么问题（事实层面，不判断值不值得解）

- **IDE 依赖**：原来要用 Cline 必须开 VS Code / JetBrains，桌面应用让 agent 不绑定编辑器
- **多任务并行 / 跨设备连续性**：桌面应用展示 queued messages、fork & edit 之前的 checkpoint、统一会话历史——支持从手机或另一台机器接着干
- **闭源模型生态锁定**：Cursor 等工具与 Anthropic/OpenAI 深度绑定；Cline 的卖点是 model-agnostic，可以切到开源权重模型
- **重复任务自动化**：Scheduled Agents（cron 调度）+ Marketplace（plugin/MCP/skill 扩展）—— 让 agent 跑 PR review / repo check / 文档更新这类周期性任务
- **协作与通知**：和 Slack / Linear / Telegram / Discord / Google Chat / WhatsApp 集成，让 agent 在 IM 里被触发

## 怎么做的（技术原理/机制，事实层面）

- **跨形态产品矩阵**（仓库 `apps/` 与 `sdk/` 目录证实）：
  - **SDK**：`@cline/sdk`（Node.js 程序化 API，可嵌到自家产品里）
  - **CLI**：`npm i -g cline`，支持 headless 模式（CI/CD 用）+ JSON 输出
  - **IDE 扩展**：VS Code Marketplace（Cursor/Windsurf 也兼容，因其内核是 VS Code）；JetBrains 插件 Early Access（**未开源**）
  - **Desktop App**：原生桌面壳，**Tauri + Bun + Next.js**——`apps/examples/desktop-app/` 是仓库内的示例目录
- **Desktop v0.0.26 新增能力**（GitHub release notes 实测）：
  - Composer 里显示当前 branch 的 GitHub PR（PR 号、合并状态、改动行数、CI 检查，依赖 `gh` CLI）
  - Customize View 重构：Tools / Plugins / Skills / Rules / MCP / Hooks 六个 tab，新增搜索栏与 per-section Enable all/Disable
  - Provider Picker 改进：Cline 和 ClinePass 现在共用一个 sign-in 配置；新增 "Set up another provider" 入口
  - Model 列表从 live catalog 拉取；ClinePass 与免费模型 cost 显示为 0
  - Telemetry 仅上报 Cline / ClinePass 请求（不再把 OpenAI / Anthropic 等三方调用回传）
  - Scheduled Sessions 默认本地时区（之前是 UTC）；执行生命周期做原子 fencing
- **核心运行机制**（README 表述）：
  - 读项目结构 → 跨文件协调改动 → 监听 linter/compiler 报错
  - 实时跑 bash 命令并显示输出
  - **Plan mode / Act mode** 切换——规划阶段探索项目，定稿后切到执行
  - **Checkpoint + 一键 undo** —— 改坏了能回退
  - `.clinerules` 项目级规则文件 + Skills + Plugins + MCP servers 扩展
- **支持的模型/Provider**（官方列表 + ClinePass 列表）：
  - Anthropic（Claude Opus / Sonnet / Haiku）
  - OpenAI（GPT 全系）
  - Google Gemini 系列
  - OpenRouter（200+ 模型）
  - Vercel AI Gateway · AWS Bedrock · Azure · GCP Vertex
  - Cerebras · Groq（高速推理）
  - Ollama / LM Studio（本地模型）
  - 任意 OpenAI 兼容 API
  - **ClinePass 包含的 open-weight 模型**：Z.ai GLM 5.3 Flash / 5.3 / 5.2；Moonshot Kimi K3 / K2.7 Code / K2.6；DeepSeek V4 Pro / V4 Flash；Qwen3.7-Max / Qwen3.7-Plus / Qwen3.8-Max；MiMo V2.5 Pro / V2.5
