## 是做什么的（如实复述，不评价）

Mem0 是给 AI agents 和 AI apps 使用的持久记忆层。开发者通过 SDK/API/CLI/MCP 接入后，可以把用户对话、偏好、历史任务和 agent 行为转成可检索的 memories，让 agent 在跨 session 和跨应用场景中保留上下文。

官网把它描述为 drop-in memory infrastructure：添加交互、抽取/更新记忆、在后续用户交互时检索相关记忆。它同时提供开源库、自托管 server 和云平台。

## 解决什么问题（事实层面，不判断值不值得解）

- 多轮 AI 应用如果只依赖当前上下文窗口，会重复询问用户偏好、丢失历史事实，token 成本和延迟也会上升。
- 官网称 Mem0 通过 memory compression engine 自动把聊天历史压缩成 compact memories，以降低 tokens 和 latency。
- 适用场景包括 AI assistants、customer support、healthcare、education、e-commerce、sales & CRM 等需要长期个性化的应用。
- 企业问题包括治理、可靠性、可观测性和数据控制；官网列 SOC 2 Type I、HIPAA Ready、BYOK、zero-trust、Kubernetes/private cloud/air-gapped、audit logs。

## 怎么做的（技术原理/机制，事实层面）

- Memory pipeline：开发者调用 `client.add(messages, user_id=...)` 写入交互，用 `client.search(query, user_id=...)` 检索记忆。
- 公开 README 描述新版算法包含 ADD-only extraction、agent-generated facts、entity linking、multi-signal retrieval、temporal reasoning。
- README benchmark（官方口径）显示 LoCoMo 92.5、LongMemEval 94.4、BEAM(1M) 64.1；同时说明 managed platform 有 proprietary optimizations，开源 SDK 结果不一定完全一致。
- 架构形态：Library 适合测试/原型，自托管 server 适合团队基础设施，Cloud Platform 适合 zero-ops production use。
- GitHub 仓库包含 Python SDK、TypeScript SDK、CLI、server、integrations、skills、docs、examples 等目录。
