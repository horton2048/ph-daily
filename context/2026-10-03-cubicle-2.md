## 是做什么的（如实复述，不评价）

本地像素风办公室视图（默认 http://127.0.0.1:3200）：每个 agent 是小人——打字=工作，举手=需要你，去休息区=完成，红屏=错误；顶栏统计等待人数。可接 Paperclip、Claude Code hooks 或自定义 JSON。

## 解决什么问题（事实层面，不判断值不值得解）

- 多 agent 并行时日志难以一眼看出状态
- 观测面板需轻量、可审计、不能误改上游

## 怎么做的（技术原理/机制，事实层面）

- 单 Node 文件标准库服务；canvas 绘制，无框架
- Paperclip 模式仅允许少数 GET
- Claude Code hooks 恒 exit 0；忽略空闲一分钟通知
- MIT；`npx @caglarutkuguler/cubicle`
