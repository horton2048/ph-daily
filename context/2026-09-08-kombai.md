## 是做什么的（如实复述，不评价）

Kombai Gallery 是永久免费浏览的 UI 灵感库，收录 20,000+ 经策展的界面。用户找到参考设计后可预览，并把它作为 Kombai 或其他 AI coding agent 的视觉上下文。

## 解决什么问题（事实层面，不判断值不值得解）

- 通用生成式 Agent 容易复用常见界面默认值，缺少明确的视觉参考。
- 设计与开发人员需要按界面实例寻找可借鉴的布局和组件。
- 参考图可缩短用纯文字描述视觉方向的过程。

## 怎么做的（技术原理/机制，事实层面）

- 通过人工策展的设计库提供移动端等分类浏览。
- 选中的设计可作为 prompt/context 交给 Kombai 或其他 coding agent。
- Kombai 主产品会扫描代码仓库并支持 400+ 前端库的实践；Gallery 本身的抓取、去重与版权筛选机制未披露。
