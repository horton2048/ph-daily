## 是做什么的（如实复述，不评价）

把 Claude Code 本地持久记忆做成可滑动审阅卡片：查看为何写入、过滤、保留或删除（进可恢复回收站）、手改或经本地 Claude Code CLI 改写；决定先暂存，确认后才写入。默认绑定 127.0.0.1。

## 解决什么问题（事实层面，不判断值不值得解）

- 记忆静默写入并在后续会话回读，可能过时或尴尬
- 需要可检查、可批量确认、可恢复的本地清理

## 怎么做的（技术原理/机制，事实层面）

- 读 ~/.claude/projects 下 memory 与 MEMORY.md；只读 CLAUDE.md
- 从 session jsonl 尝试还原写入原因
- 确认后写 ~/.scmd/reviewed.json 与 trash
- Node >=18
