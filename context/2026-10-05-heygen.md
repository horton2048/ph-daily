## 是做什么的（如实复述，不评价）

HyperFrames Studio 是 HeyGen 推出的桌面视频编辑器：用户接入自己的 Claude Code 或 Codex，描述想要的视频，agent 用 HyperFrames（以 HTML 写视频并渲染为 MP4）制作，之后人和 agent 在同一编辑器里协作修改：在画面上画圈写指令、对任意元素留言后批量发送、从“爆款视频的代码复刻”模板起步，也可手动改时间线、片段速度并导出最高 4K 的 MP4/WebM/MOV。

## 解决什么问题（事实层面，不判断值不值得解）

- 首稿之后的修改很难在聊天里描述清楚“第几秒哪个字要改”（PH 首评）

## 怎么做的（技术原理/机制，事实层面）

- HyperFrames 把视频写成 HTML，可 diff 的时间线（评论者观点）
- Studio 在画面层收集标注与评论，转成 agent 可执行的编辑
