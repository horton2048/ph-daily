## 是做什么的

Kilo的移动端入口，用手机继续编码任务、审查代码及处理代理后续工作。iOS与Android现均有官方安装入口。

## 解决什么问题

编码代理执行时间较长，用户离开电脑后仍需补充指令、查看检查结果或审阅变更。

## 怎么做的

Run on选择云端或已连接的kilo remote实例；本地任务仍在电脑执行。支持队列消息、会话目标、远程命令、PR评审与合并，远程能力取决于CLI版本。

## 团队 / 背景 / 融资

## 定价 / 商业模式

平台个人版$0，Teams $15/用户/月，推理按供应商费率计，购买credits有5%处理费；可选Kilo Pass $19/月起。云计算另有计价，不能把手机应用免费视为任务运行免费。

Kilo-Org/kilocode主仓库已核实MIT；移动应用的具体源码覆盖未单独核实，不能将主仓库许可证自动推广到每个客户端。可选遥测在首次启动询问，默认预选但选择前不启动。
