## 是做什么的（如实复述，不评价）

Recall.ai 是一个会议录制 API 平台，本次上榜的"Startup Program"是一个面向早期团队的定价计划。
该计划为初创团队提供会议录制基础设施：前 10,000 小时按 $0.25/小时收费，包含工程师支持、
快速机器人入会（fast bot joins），以及每条录制产出的完整产品（转写、字幕、摘要等）。

本质上是 Recall.ai 把其会议录制 API 以低于标准价的方式卖给初创团队，降低自建会议录制基础设施的门槛。

## 解决什么问题（事实层面，不判断值不值得解）

- 早期团队需要会议录制功能（客服记录、会议纪要、合规存档等），但自建录制基础设施成本高
- 现有会议录制 SaaS（Otter、Fireflies 等）按席位收费，API 层方案少
- 初创团队预算有限，需要低价 + 工程师支持来快速集成

## 怎么做的（技术原理/机制，事实层面）

- 提供 API + SDK，开发者通过调用 API 让机器人加入会议并录制
- 支持 fast bot joins（快速入会，减少会议开始时的等待）
- 每条录制产出：转写文本、字幕、摘要等多模态产物
- 具体录制技术栈、bot 架构未在 PH 页面披露
