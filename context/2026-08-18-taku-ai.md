## 是做什么的（如实复述，不评价）

Taku 是一个 AI workflow / app 的"借用 + 改造（remix）"市场。三种使用路径：

1. **Marketplace（市场）**：浏览他人做好的 AI app、agent、workflow，"一键借用"变成自己可运行、可保存、可改的本地工具。
2. **Stacks（堆叠）**：用自然语言描述目标，Taku 自动从市场拉取合适的 app/agent/skill 组成一条工作流，无需安装或配置文件。
3. **Stax（发布格式）**：创作者把自己的 AI 配置打包成"Stax"，他人可安装、运行、remix。官网展示类函数语法定义示例（如 Brand voice stax，带 inputs 与 style 参数）。

产品形态含 Web 与 Apple 平台原生应用（官网有"Download for Apple"）。集成：Claude Code、Codex、email、calendar、Notion、Slack、spreadsheets、docs（PH 评论区创始人回复确认）。底层模型集成 OpenAI 与 Claude（PH "Built with" 字段）。

平台统计（官网公开）：12,000 apps & skills、3,400+ creators、1.2M runs/月、"0 installs needed"。

## 解决什么问题（事实层面，不判断值不值得解）

- **AI 应用层"最后一公里"门槛**：创始人称普通用户要"装工具、找资源、写 prompt、配 API、babysit 一切"，多数人卡在配置层而非模型层。CMO Emily L 自称"AI tool hoarder"——收藏了 Codex、Claude Code、若干 GitHub repo，但实际工作流没变。
- **AI 能力变成"infrastructure"而非"app"**：创始人观点是"下一亿 AI 用户不会去学 GitHub 或调试环境，他们期待 AI 像 normal software 一样工作"。
- **创作者分发难**：懂行的 practitioner 配置出好用的 AI workflow，但没有分发渠道让别人用上——Taku 想用 Stax + 按运行付费解决。

## 怎么做的（技术原理/机制，事实层面）

- **运行方式**：描述目标 → Taku 从 marketplace 自动组装 stack → 立即运行 → 可 tweak / share / 发布自己的 Stax。
- **Stax 格式**：类函数定义，含 inputs 和 style 参数，把一段 AI 配置（prompt + skill + agent + 集成）封装为可分发单元。
- **集成**：Claude Code、Codex、email、calendar、Notion、Slack、spreadsheets、docs；其他按需提供。
- **失败/更新处理**（PH Q&A）：
  - Stax 当前是 snapshot 系统，创作者更新后用户副本不会自动同步——创始人称正在探索"intelligent update strategy"以兼容用户自定义。
  - 目标是 fully automatic merge，"把这种决定留给非技术用户会出问题"。
  - 若 Stax 内某个 capability 报错，"Taku agent will automatically identify bugs and issues"——非 baked-in，可现场定制/组合。
- **模型**：OpenAI、Claude（PH Built with 字段）；底层技术栈官网未详细披露。
- **平台**：Web + Apple 原生应用（官网下载按钮）；Windows / Linux 版本状态未查到。
- **GitHub**：组织 github.com/taku-ai 存在但 0 个公开仓库，闭源。未见开源信号，未进一步查 GitHub。

## 定价 / 商业模式

- **Freemium**：免费层可用，"Start free, run real workflows, and upgrade when Taku becomes part of your work."
- **付费档**：Monthly / Annual（年付 30% off）。具体美元金额官网未公开展示，需进入付费流程才能看到。
- **创作者经济**：发布 Stax 后按运行次数获 **Taku Credits**；创始人称正在开发"Patreon / Substack 式"完整 monetization 与订阅 bundle，让创作者按订阅收费。
- 当前阶段：创作者按使用量获得 Credits 奖励，正式变现机制尚未上线。
