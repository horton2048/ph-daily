## 是做什么的（如实复述，不评价）

本地优先的 MCP gateway：一个本地 MCP server 聚合多个 MCP server，让多个 AI agent 共用一套工具配置。核心创新是 lazy discovery——不再让每个 server 把完整工具列表灌进每次请求的 context，而是暴露 4 个 meta-tools 让 agent 按需搜索加载。Windows / macOS / Linux，无需账号、无云。

两部分架构：桌面 app（Tauri + React，管理 servers/profiles/credentials/客户端连接）+ `toolport-gateway` 二进制（各 AI client 经 stdio 启动，读共享 registry.json + OS keychain，路由到下游 server，工具名加命名空间前缀如 `stripe__list_charges`）。

## 解决什么问题（事实层面，不判断值不值得解）

- 官方（README/PH 描述/创始人评论口径一致）："Every MCP server you connect dumps all of its tools into context on every single request, and it adds up fast: just 3 servers (62 tools) cost ~24,000 tokens of definitions before you've asked anything."（3 个 server ≈ 24k tokens 定义费，还没开口提问。）
- 创始人自述动机："I built Toolport because I was configuring the same MCP servers over and over. Claude Desktop, Claude Code, Cursor, Codex, VS Code, each one wanted its own JSON file with the same API keys pasted in as plain text."（同一批 MCP server 反复配置、每个客户端各自的 JSON、API key 明文粘贴。）
- 测量结果（官方口径，BENCHMARK.md 可复现）：工具定义 tokens 减 74–91%（同任务成功率）；总量 tokens 最多减 91%；单请求工具定义开销降 96%、真实 415-tool 目录降 99.5%；示例 23,698 → 886 tokens。
- 目标场景：多 agent 客户端（Claude Desktop/Claude Code/Cursor/Codex/VS Code 等）+ 多 MCP server 的开发者的配置与 token 开销问题。

## 怎么做的（技术原理/机制，事实层面）

- lazy discovery：暴露少量 meta-tools，agent 按需搜索加载工具，而非全量灌进 context。
- 自动检测 33 个 AI 客户端并写入对应 config 文件（Claude Desktop JSON、Claude Code `~/.claude.json`、Cursor `~/.cursor/mcp.json`、VS Code JSON、Codex TOML、Zed context_servers 等）；"No restarts"。
- 密钥存 OS keychain，运行时注入，从不在 client config / 云端。
- 安全特性（官方口径）：tool integrity（指纹每工具，检测 rug-pull——定义被改、tool poisoning——描述中藏指令，默认开启、全本地）；content defense / anti-agentjacking（把带注入式指令的返回内容标为外部数据而非指令）；human-in-the-loop 审批（破坏性调用暂停，Deny 真正阻断，审批绑定到审批时看到的确切参数）；单开关可全局隐藏所有破坏性工具；内置每 server 延迟/错误率与完整工具调用审计轨迹。
- 支持最新 MCP spec（2026-07-28）两侧兼容，旧客户端/旧 server 不受影响。
- Code mode：让 agent 把一整条工具序列当作一个沙箱化的 server-side 脚本运行，而非每次调用都往返模型。
- 无头/容器：MCP over HTTP/SSE；Docker 镜像 `ghcr.io/tsouth89/toolport-gateway:latest`；gateway 原生讲 HTTP/OpenAPI，Open WebUI 等可直接连接。
- 安装：macOS `brew install --cask tsouth89/toolport/toolport`；Linux 安装脚本或 `.deb`（首选）/AppImage；Windows `.exe`；Win/macOS 安装包 code-signed、macOS notarized。
- 已知问题：Linux-only 的 glib `VariantStrIter` soundness advisory（RUSTSEC-2024-0429），局限于 webview binding 层，不影响 Win/macOS。
