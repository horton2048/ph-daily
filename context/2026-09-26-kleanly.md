## 是做什么的（如实复述，不评价）

Kleanly 是一款 macOS 菜单栏 / 刘海工具，运行后短暂禁用 MacBook 自带的内置键盘和触控板输入，让用户可以放心擦拭屏幕、键盘而不会误触或中断正在播放的视频。无刘海的 Mac 退化为屏幕顶部的小标签。屏幕保持常亮（不进入睡眠）。

## 解决什么问题（事实层面，不判断值不值得解）

- 擦屏幕/键盘时容易误触按键、触发快捷键、打断正在播放的视频或通话
- 传统的"合上盖子/让 Mac 进入睡眠"会中断媒体播放
- 第三方脚本方案解锁方式不友好（需要按特定键盘组合，但键盘正在被擦）
- 熊孩子摸键盘时希望临时锁住输入

## 怎么做的（技术原理/机制，事实层面）

- 控件入口：带刘海的 MacBook Pro 上，交互控件住在屏幕顶部的 TrueDepth 摄像头"刘海"区域；无刘海机型退化为菜单栏/屏幕顶部的小标签
- 输入屏蔽：通过申请 macOS Accessibility 权限，使用 Event-tap API 拦截内置键盘和触控板的 HID 事件；外接键鼠不受影响
- 解锁手势：双击触控板恢复输入（设计成"擦完手往上一拍"就能解锁）
- 屏幕清洁辅助：可选的全屏纯黑覆盖层，让屏幕上的灰尘/指纹/油污更显眼
- 进程与更新：内置 in-app updater；用户可在应用内自己停用旧 Mac 的许可证并转移到新 Mac
- 技术栈（页面披露）：用 Swift 开发，依赖 macOS 12 Monterey+，Intel 芯片也支持；官网/演示用 Remotion + Cloudflare Workers 部署
