## 是做什么的(如实复述,不评价)

Typewise Nova 是一个**面向企业客服场景的 agentic AI 平台**——把客户请求(邮件、聊天、WhatsApp、社交渠道)在端到端层面自动化解决,而不仅是给人工坐席做补全建议。

核心由两层组成:
- **AI Supervisor Engine(监督引擎)**:对每一条进来的客户请求做意图识别和路由,决定交给哪个下层 agent 处理
- **多代理编排(Multi-Agent Orchestration)**:三类 agent 协同工作——
  - Specialist agents(专业 agent):处理特定业务场景
  - Knowledge agents(知识 agent):从企业知识库/文档/历史工单里检索答案
  - Action agents(执行 agent):调用下游系统完成退款、改单、开 ticket 等动作

平台定位是「**一个平台,解决每一次客户请求**」(官网"One platform. Every customer request, resolved."),口号层面的承诺是 AI 系统能在使用过程中**自我构建和自我改进**(对应 PH tagline 的 "builds and improves itself")——具体自我改进机制官方未在公开材料展开技术细节。

运营形态支持**自然语言指令**(不需要写代码)、**人在环审批**(Hybrid Intelligence,human-in-the-loop),声称对接 3500+ 集成(CRM/ERP/helpdesk 等)。

## 解决什么问题(事实层面,不判断值不值得解)

- **客服人力成本与响应时效**:Beurer 案例公开宣称 **90% 解决率** 是当前使用效果,官方在更早材料中给出过 **3 倍坐席效率提升、5 倍等待时间下降** 的对比数字(对比对象和基准未披露,仅营销材料出现)
- **跨渠道一致性**:同一请求在邮件/聊天/WhatsApp/社交渠道都能被同一套 agent 体系接管,避免多渠道体验割裂
- **企业知识资产未被 LLM 利用**:Knowledge agent 把散落在文档、历史工单、产品页里的知识结构化给 LLM 用,减少「AI 答非所问」
- **多语言客服**:官方渠道提到支持 **100+ 语言** 实时翻译,适合跨境电商和多区域客服中心
- **欧盟数据主权诉求**:在 ISO 27001、GDPR、EU AI Act 合规下提供 EU 数据驻留——主打对欧洲合规敏感的零售/制造/医疗客户

## 怎么做的(技术原理/机制,事实层面)

- **自研垂直 LLM**:Typewise Custom LLM,声称在客服场景下**比 GPT-4 准确率高 2 倍**(基准和测试集未公开)。技术路线是**自训练领域专用模型**,而非直接调用通用大模型 API
- **AI Supervisor 架构**:监督引擎是顶层调度层,接收请求 → 理解意图 → 路由到合适的 specialist/knowledge/action agent 组合 → 汇总结果返回。这是**多 agent 编排**而非单 agent 一次性回答
- **自然语言指令配置**:运营人员用自然语言描述业务规则和 SOP,无需编程即可配置 agent 行为(类似 agent builder 的低代码形态)
- **人在环(Hybrid Intelligence)**:高风险或低置信度的动作(退款、改单)由人工审批,AI 在「shadow mode」(影子模式)下给出建议
- **集成层**:3500+ 集成,涵盖主流 CRM(Salesforce/HubSpot)、ERP(SAP)、helpdesk(Zendesk/Freshdesk)等
- **自改进机制("builds and improves itself")**:官网/营销材料反复出现这个表述,但**具体技术机制(是 RLHF/反馈闭环/人工纠正回写知识库/agent 自动 re-prompt 等)在公开材料中未展开**——本次未查到对应技术博客或白皮书
- **失败/误报处理**:基于 human-in-the-loop 设计,置信度低的决策转人工;无公开技术博客说明幻觉率/拒答率等指标

## 定价 / 商业模式

- **核心模式:按效果付费(Outcome-based pricing)**——这是和传统 SaaS 最显著的差异
  - 完整解决一笔客户请求 = **$1-2**(每 resolved ticket)
  - 部分解决、需要转人工(handoff) = **$0.5**
  - 未解决/失败 = **免费**(客户不付费)
- **与按席位计费的对比逻辑**:厂商利益与「AI 实际帮客户解决了多少问题」绑定——客户不为试用、空跑、失败埋单
- **价格门槛**:起步价未单独披露(企业向),需要 sales 对接
- **消费级业务**:Typewise 早期还有面向消费者的六边形键盘 app,该公司由键盘起家,2024 年后主推 B2B Agentic AI
