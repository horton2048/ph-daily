## 是做什么的（如实复述，不评价）

Opengeni 是把 agent 嵌进自有产品所需的基础组件：可恢复的会话（带可回放历史）、隔离沙箱（凭证与记忆内置）、接入自有 API（OpenAPI/GraphQL 规范或 MCP 服务器）和 100+ 带 OAuth 的集成、风险动作前的人工审批、步骤/token/花费可视化、按客户隔离的工作区与可换模型。集成三步：服务端加 API key、用已有认证挂载 handler、在应用里展示 agent。

## 解决什么问题（事实层面，不判断值不值得解）

- agent 跑通一次只是开始：保持运行、安全执行、连接用户账号、人工审批、搞清做了什么和花了多少钱才是工作量（PH 首评）
- 团队反复重造这套底座

## 怎么做的（技术原理/机制，事实层面）

- Durable sessions：worker 重启或标签页关闭后从事件点续跑
- 沙箱隔离 agent 代码与密钥；短期作用域 token
- 行级安全的多租户；模型可选 OpenAI / Azure OpenAI / OpenRouter / 任意 OpenAI 兼容端点
