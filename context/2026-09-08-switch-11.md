## 是做什么的（如实复述，不评价）

Switch 是连接既有 AI Agent 与团队聊天工具的开源协作层。团队无需换掉 Claude Code、Codex 或 OpenCode；Agent 以具名成员进入频道，在房间上下文、角色、权限和知识约束下收发任务。

## 解决什么问题（事实层面，不判断值不值得解）

- Agent 常驻 CLI 或独立聊天界面，团队协作依赖人工复制上下文。
- 团队需要把 Agent 放进已有频道，同时管理身份、权限、会话与部署。
- 支持本机或自有服务器运行，面向不愿把协作数据交给第三方托管的场景。

## 怎么做的（技术原理/机制，事实层面）

- 每种聊天平台通过独立适配器连接：Slack Socket Mode、Teams HTTP listener、Discord gateway websocket、Telegram long polling、Mattermost websocket。
- Matrix/Tuwunel 作为内部消息总线；Room Service、Gateway API 与 PostgreSQL 管理房间、角色、权限和状态。
- Switch Console 是 Electron 桌面应用，负责启动 Agent、保存身份/工作目录/提供商配置，并可启动本地服务器。
