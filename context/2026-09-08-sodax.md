## 是做什么的（如实复述，不评价）

SODAX SDK 为应用提供跨网络的数字资产操作模块，包括 swap、借贷、bridge、staking 和资产迁移。TypeScript 团队可用核心 SDK、钱包连接层和 React dApp kit；非 TypeScript 系统可直接调用 REST API。

## 解决什么问题（事实层面，不判断值不值得解）

- 应用若自行整合多链钱包、报价、路由、流动性与结算，需要维护多套协议适配。
- Rust、Go、Python 服务和 AI Agent 不一定适合采用 TypeScript 客户端架构。
- 集成方需要在资产流中配置自身手续费，而不重建执行基础设施。

## 怎么做的（技术原理/机制，事实层面）

- `@sodax/sdk` 提供 swaps、lend/borrow、bridge、staking、migration、Backend API 与 Intent Relay API。
- wallet-sdk-core 管理 EVM、SVM 与非 EVM 钱包；wallet-sdk-react 提供 React provider/state；dapp-kit 提供 UI、hooks 与 utilities。
- SODAX 协调路由和结算，由独立 solver 聚合流动性并填单；API 为非 TypeScript 调用者暴露相同能力。
- SDK 和 API 均支持 partner fee；不同执行路径的默认值与覆盖规则不同。
