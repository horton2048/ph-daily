## 是做什么的（如实复述，不评价）

Driven 是一个网页端 AI 投资代理（investment agent）平台。核心结构：把一个通用 AI 模型（Claude、GPT、Gemini 等）包装进"投资专用 harness"——实时市场数据、可复用的投资工作流（Skills）、持久策略记忆（Playbooks）、投资组合上下文、文件和定时任务。用户创建自己的 Agent，Agent 负责研究、监控、策略构建、模拟下单等工作，用户坐在上面做决策。

官网口号是 "Your Investment Team, Driven by You"（你的投资团队，由你驱动）。创始人 Zania 在 PH 发布评论中强调：不打算做"又一个 dashboard 或带行情数据的聊天机器人"，产品"更像一个 AI 投资团队而非搜索框"。形态上从对话出发，覆盖从选股、数据收集、分析到行动的完整投资流程。2026-08-04 上线当天状态为模拟交易（paper trading）可用、真实资金交易（live trading）"即将推出"。

## 解决什么问题（事实层面，不判断值不值得解）

- **信息过载**：创始人开场评论原话 "Investors are not short on information. They are overwhelmed by it."（投资者不缺信息，是被信息淹没）。About 页同样表述：个人投资者不是因为缺数据而失败，而是"淹死在数据里"。
- **工具碎片化**：多位评论者提到"同时用五个工具做研究和执行"（Ayesha Mughal 评论）、"在标签页之间切换做研究、监控信号、管理组合"（官网用户引语 Wenz）。创始人 Wei 承认"你已经点出了投资研究中的痛点"。
- **错过隔夜行情**：评论者 Madison Marley："手动操作错过了太多隔夜波动"。创始人 Zania 回应："市场不会等我们在线，错过隔夜波动很痛苦。"
- **通用 AI 在投资场景不可靠**：官网 What's New 博客（2026-04-27）原文：让通用 AI "analyze this stock" 会得到"听起来像金融教科书写了条推文"的结果——混合不具名的估值方法、依赖训练数据里的常见内容、编造带引用的目标价。对真金白银的投资者是"责任"而非"把戏"。
- **现成工具门槛**：About 页称强大工具存在但对多数投资者不可及："太技术化、太碎片化、不敢把敏感数据交给它们"。
- **目标场景**：美股/港股/A股市场的活跃个人投资者、分析师、顾问、活跃交易者，想要专业研究工作流和自动化但保留决策控制权。

## 怎么做的（技术原理/机制，事实层面）

来源：官网、llms.txt/llms-full.txt、docs.driven.ai、PH 创始人评论

- **数据层**：连接 260+ 专业市场数据端点（官网首页与 llms-full.txt 口径；About 页写 230+），跨 30+ 数据类别，覆盖美股、港股、A股个股，辅助 ETF、美股权证、宏观、加密、外汇、大宗商品。数字"来自数据库，不是模型记忆"（docs）。覆盖与刷新频率按市场/数据集而异。
- **Skills（技能）**：官网定义"不是 prompt 模板，而是基于具体可引用分析框架的可重复命名工作流，以真实代码运行，保持一致性与可审计性"。内置基于巴菲特、Markowitz 等方法论的专业 Skills（Stock Screener、Portfolio Monitor、Market Pulse、Insider Tracker、Sector Radar、Data Lab 等）；Skill Store（2026-07-23 上线）允许用户发布/分享/迭代自己的 Skills。
- **Playbook（剧本）**：每个投资组合的持久策略记忆——universe（标的池）、watchlist、风险规则、仓位管理、基准、筛选条件、买卖纪律。跨会话持续，塑造 Agent 每次决策。
- **Scheduled Tasks（定时任务）**：Agent 按计划自动运行简报、监控、提醒，7x24 执行，"即使应用关闭也继续工作"。
- **Portfolio + Paper Trading（组合与模拟交易）**：组合跟踪现金、持仓、订单、业绩；模拟交易用真实行情 + 虚拟资金。自然语言下单：用户描述意图，Agent 翻译成订单、展示对组合的影响、在模拟账户执行；限价单由 Agent 管理（可见订单 ID、可按 ticker 取消挂单）。
- **模型策略**：多模型集成，按订阅档位解锁——Claude（Opus 4.6/4.7/5、Sonnet、Fable 5）、GPT-5.6（Sol/Terra/Luna 三档）、Gemini 3.6 Flash 等。2026-07-27 起 Claude Opus 5 支持百万 token 上下文、图片/PDF 输入。
- **自主执行边界（创始人评论区说明）**：默认情况下订单执行前要求用户确认；自动化执行需用户先设定明确规则（允许做什么、条件、限额）。Zania 原话："目标是做出一个不依赖人的选择，而不是一个黑箱交易机器人""不应该在你睡觉时凌晨 3 点自动下单"。
- **可追溯性**：答案锚定实时/结构化数据源而非训练记忆，展示来源；2026-06-24 上线"可追溯引用"（下划线、悬停显示来源+更新时间+调用工具+原文片段）；2026-07-31 增强为实时引用（生成过程中来源即时出现、关键声明下划线、悬停高亮原文并直链来源页）。
- **自研 Harness**：创始人 Wei 评论区称 Driven 有"自研的 Harness"用于投资场景，每个研究数据点和结论可追溯。
- **渠道**：Web、mobile、Telegram（含群内 @ 提及）、WeChat。
- **公司主体说明**：官网多个页面标注 "Made by investors, for investors"、"© SNOWBALL WEALTH PRIVATE LIMITED"。

## 定价 / 商业模式

来源：driven.ai/pricing + llms-full.txt（2026-08-05 抓取）

- **免费档**："Free to start"（免费开始）；PH 页标注 "Free Options" badge 与 "First Month Free"
- **Pro $20/月**（年付 $16.67/月）：标准用量、多数主流模型、1 个 Agent、5 个定时任务/Agent/天、3 个组合/Agent、2GB 存储；**首月免费**
- **Max $100/月**（年付 $83.33/月）：5x 用量、解锁全部核心模型、3 个 Agent、10 定时任务/Agent/天、5 组合/Agent、4GB 存储、新功能抢先体验
- **Ultra $200/月**（年付 $166.67/月）：20x 用量、全部模型（含 Claude Fable 5）、6 个 Agent、20 定时任务/Agent/天、10 组合/Agent、8GB 存储、新功能抢先、高峰优先接入
- **计价模式演变**：2026-06-01 订阅制正式上线（此前 2026-04-30 曾把 credits 手动充值制改为"每 5 小时 + 每 7 天两个滚动窗口自动重置用量"）。现为订阅制，按 Agent 数量与用量档位分层。
- 模式要点：订阅 + 用量分层，无 per-trade 佣金（模拟交易阶段）。

## 评论区反馈（事实摘录，不评价）

- **Gal Dayan（质疑）**：担心"24/7 监控 + 订单执行"——从"agent 决定行动"到"订单实际发出"之间的故障安全机制是什么？默认是否有人工确认步骤？
  - **Wei（创始人）回复**：默认情况下订单执行前会要求确认；用户可设定规则允许自动执行，"Driven 会基于这些规则及其对用户的理解做综合判断"，类似私人理财顾问。
  - **Zania（创始人）回复**：默认执行订单前要求确认；Agent 可以监控和准备，但"不应该在你睡觉时凌晨 3 点下单"；自动化需要用户明确的规则（允许什么、条件、限额）。"目标不是做一个黑箱交易机器人。"
- **Madison Marley（认可）**：24/7 监控是打动我的点，手工操作错过太多隔夜波动。
  - **Zania 回复**：市场不会等我们在线，错过隔夜波动很痛苦。
- **Samra Habib（提问）**：Playbooks 可定制程度如何？能按不同投资风格建自己的工作流吗？
  - **Wei 回复**：Driven 先学习用户的投资风格和偏好，再提供定制化投资建议，"像一个真正了解你的投资顾问"。
  - **Zania 回复**：Playbook 可围绕不同投资风格定制；哪怕只有一个粗略想法或一句话，也能通过对话变成一个 Playbook；"对新手也友好"。
- **Hammad Shams Uddin（质疑）**："trusted" 是个大词——输出是基于查询时的申报文件/行情数据，还是模型训练记忆？会展示来源吗？
  - **Zania 回复**：答案锚定实时或结构化数据源而非仅靠模型训练——包括申报文件、行情、基本面、新闻、分析师数据、持仓、内幕交易等；会展示来源，用户"可以在行动前核对"；情绪分析可打开原始来源（如 X 主页/帖子）。
  - **Wei 回复**："trusted" 需要可靠实时的金融数据源加上 Driven 自研的 Harness（用于投资场景）；"每个研究数据点和结论都可追溯"。
- **William Buck（认可）**：把从想法到执行统一在一个 agent 里（而非五个割裂工具）很有吸引力；会"从小处开始、逐步建立信任"。
  - **Zania 回复**：很多工具单点做得不错，难的是"让上下文保持活跃"；同意从小处开始逐步建立信任。
- **Ayesha Mughal（认可）**：我试过同时用五个工具做研究和执行；如果真能弥合这个差距我就有兴趣。
  - **Zania 回复**："信息找到了"和"知道拿它怎么办"之间的差距，正是投资 agent 能帮忙的地方。
- 创始人 Zania 开场还在评论区向社区提问：你最先把 AI 投资 agent 用在哪个环节（找想法 / 监控信号 / 跟踪财报 / 追踪组合 / 准备操作）。
