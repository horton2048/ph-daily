## 是做什么的（如实复述，不评价）

把全球 4000+ 独立开发者（indie makers / solo founders）按他们自我报告的地理位置，落到一张可缩放的 2D 世界地图上。每个图钉背后挂一张「活」的 profile 卡片，从该用户的 X (Twitter) bio、个人站、当前在做的项目里抓取信息，再用一个积分（points）反映其「intro 帖」获得的互动量。用户可以在地图上自然语言提问（"Talk to the map"），比如「做 AI 工具的」「用 Next.js 的」「在柏林的」，让搜索结果直接呈现在地图上。简言之：在 X 之上加一层「见面/打招呼 (meet & greet)」的地理视图。

## 解决什么问题（事实层面，不判断值不值得解）

- 独立开发者社区目前主要散落在 X (Twitter) timeline、IndieHackers 论坛、Product Hunt 等平面 feed 里，缺乏「按地理位置发现附近的同好」这类空间维度。
- 想找「同城市 + 同技术栈 + 在做 AI 工具」的潜在合作者/技术交流对象，目前需要手动交叉过滤多平台数据。
- 投资人/招聘方/记者想批量定位某区域独立创作者时，没有现成的可视化入口。

## 怎么做的（技术原理/机制，事实层面）

- 数据源：以 X (Twitter) profile 为单一锚点（一切身份/项目信息都挂在 X handle 下面），用户通过提交自己的 X handle 自助上榜；地图点位的经纬度来自用户自报或 X bio 中可解析的位置信息。
- 搜索：「Talk to the map」是自然语言接口（具体模型未披露），接受按 niche、技术栈、城市等维度的口语化查询，再在地图上高亮匹配 maker。
- profile 卡片：从用户的 X bio、个人站和「当前在做项目」聚合而成，并随用户更新而刷新（「live」）。
- 排序：每个 maker 有一个 points 数值，来自其 intro 帖的互动量（点赞/回复等）。
- 技术栈：官方 Built With 标注 Claude Code + Vercel + Typesafe。
