## 是做什么的（如实复述，不评价）

一个 **Android 启动器（launcher）**，把手机的"桌面"替换成一个极简界面——没有壁纸、没有图标、没有小组件、没有小红点——只显示今天要做的任务、今天拿起手机的次数（以及其中"空拿"的次数）、和你常用的六个工具。

区别于传统屏幕时间工具：**它衡量的是"你拿起手机的次数"，而不是你用了多久**。核心论点是：很多次拿起手机是"无意识地解锁、看一眼、又锁回去"，这些"空拿"才是分心的真正信号。

使用 Android 系统的 Usage Access API 计数。完全离线：没有服务器、没有账号、没有广告、没有分析 SDK。

## 解决什么问题（事实层面，不判断值不值得解）

- **空拿（empty pickups）造成的注意力碎片**：用户解锁看一眼就锁回去，但每一次都打断了正在做的事
- **屏幕时间指标太迟钝**：用了几小时是结果，"为什么会拿起手机"才是源头
- **传统数字健康工具要么太弱（只显示数字）要么太狠（强制锁屏）**：创始人选择"在门口拦截"——在你打开 App 之前给你一次暂停和反思的机会
- **隐私敏感人群**：不想用 Google / Apple 自带健康方案、也不想用要账号的 SaaS
- 目标场景：被分心困扰的职场人 / 学生 / 极简主义者 / 注重隐私的用户

## 怎么做的（技术原理/机制，事实层面）

- **计数器（The Count）**：用 Android **Usage Access API** 统计今日拿起次数和"空拿"次数；显示在桌面顶部。权限是**可选**的——拒绝的话桌面其他功能照常工作，只是这个计数器关掉
- **今日一句话（The Sentence）**：桌面顶部显示今天要做的事；周一做一个简短的周计划，挑 5 件事，每天浮现一件；做完自动归档
- **时间黑洞标记（Time Sinks）**：把 Instagram、YouTube 这类 App 标记成"time sink"；从桌面点开它们时，先弹一个**几秒钟的暂停屏**，让你输入"打算停留几分钟"。不锁屏，回来后对比"说的 vs 实际"
- **Day Blocks**：把一天分成 Morning / Work / Evening / Night 四个时段，每段可以配不同的摩擦强度——更长的暂停、甚至直接隐藏 App
- **抽屉**：所有 App 还是能通过上拉抽屉打开；不常用的可以隐藏
- **反无障碍后台服务**：创始人明确拒绝靠后台无障碍服务去测滚动距离这类深度数据，理由是"耗电 + 隐私"。所有检测走系统 Usage Access API
- **多语言**：支持 9 种语言

## 评论区反馈（事实摘录，不评价）

- **Aryan Thakor**（7h）：建议加一个"滚动距离折算成地图路径"（比如"你已经滚过巴黎了"）的指标
  - **Ali Sarac 回复**：喜欢这个想法，但 Fewer 规则是不挂后台无障碍服务，测滚动距离需要那种侵入式权限。目标是"在你开跑之前在门口拦住"，不是马拉松中段测距离
- **Dmitry Guzerchuk**（2h）：说"用拿起次数比屏幕时间更准，自己一半的拿起都是什么都没干"；问 iOS 计划和 Screen Time API
  - **Ali Sarac 回复**：无 iOS 计划。FamilyControls + DeviceActivity + ManagedSettings 可以做拦截/定时/阈值回调，DeviceActivityReport 扩展甚至能渲染每次拿起和通知数，但这些数据**被系统设计成封在 Report Extension 里**——不能导出、不能留历史、不能放桌面组件。所以 iOS 版的 Fewer 只能是"你打开 App 才看得到一份报告 + 一个拦截器"——桌面这个产品形态在 iOS 上不成立。如果苹果哪天允许桌面组件读拿起次数，他当天下午就去做
