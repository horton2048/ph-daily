## 是做什么的（如实复述，不评价）

Siteprint 是 Mac 版 Safari 扩展：打开任意网站点一下，测量页面颜色及其角色、字号阶梯、间距、圆角和每个区块的布局蓝图；免费版可检查与导出 token，Pro 版生成一段给编码 agent 的精确提示词和 DESIGN.md、提供主题、让 agent 通过 MCP 直接读扫描结果，以及用 Compose 混合两个站点的风格。

## 解决什么问题（事实层面，不判断值不值得解）

- 把参考网站交给 AI 时只有色值列表，agent 不知道每个颜色的用途（评论认同）
- 作者常用 Safari，Chrome 同类扩展很多但 Safari 少（首评）

## 怎么做的（技术原理/机制，事实层面）

- 本机运行，无上传；Apple Intelligence 可选
- Pro 经 MCP 让 agent 读取扫描
