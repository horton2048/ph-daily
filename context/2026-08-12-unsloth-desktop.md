## 是做什么的（如实复述，不评价）

Unsloth Desktop 是 Unsloth（知名开源 LLM 微调加速库）推出的桌面客户端，让用户无需终端经验即可在本地运行和训练 AI 模型，覆盖 LLM、图像/视频扩散模型、音频模型。原生支持 Mac/Windows/Linux。

## 解决什么问题（事实层面，不判断值不值得解）

原本 Unsloth 的模型微调能力面向有命令行经验的开发者；Desktop 版把这套能力封装成无代码工作流,降低本地跑/训练模型的门槛，一条评论称"不希望本地 AI 变成周末折腾项目的人也能用"。

## 怎么做的（技术原理/机制，事实层面）

- 一条命令 `unsloth start` 接入本地 GPU
- 提供模型量化选项做优化
- 可离线运行模型
- 支持接入 Claude Code 等 agent 工具
