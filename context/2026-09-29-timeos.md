## 是做什么的（如实复述，不评价）

Timeless 官网展示 Playbooks：用户用自然语言描述希望会议结束后产出的工作，系统将 playbook 接到会议、转录和日历数据，并在会议后或设定时间执行。PH 的 Timeless Code listing 将其描述为在 Claude Code 内运行的 meeting notetaker；该精确集成机制与官网 Playbooks 的关系仍待产品页确认。

## 解决什么问题（事实层面，不判断值不值得解）

- 会议常有待办、跟进和承诺，但单纯摘要不一定将其送入团队实际使用的地方。
- 反复从会议转录、日历中整理晨报、待办等产物。
- 需要按用户意图定制会后动作，而不是只收一份会议纪要。

## 怎么做的（技术原理/机制，事实层面）

- 用户用自然语言描述任务，Claude 生成 playbook 示例代码，接入 Timeless 的会议、转录与日历接口。
- 可配置在每次会议后或按计划通知；官网列出待办、Morning Brief、Promise Tracker 等示例。
- 官网页面同时展示“Nothing leaves your Mac”的 Walkie-Talkie 示例；不能据此推断所有 Timeless 会议数据都仅在本机处理。
- 更完整的数据保留、云端处理与 Claude Code 安装方式未查到。
