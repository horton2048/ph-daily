## 是做什么的（如实复述，不评价）

Manager Agents 是提供给一线管理者的 AI 助手集合，官网展示会议、反馈、认可等 agent。Meeting Agent 从会议建立上下文，再供其他 agent 使用；产品用于准备一对一会议、给反馈、识别团队参与度等管理工作。

## 解决什么问题（事实层面，不判断值不值得解）

- 管理者的 1:1 记录分散在多个地方，难以跨对话保持团队背景。
- 准备反馈、认可员工、跟进团队参与度等管理工作常缺少 HRBP 的即时支持。
- 企业部署需要与 HCM 系统、身份管理及组织级治理集成。

## 怎么做的（技术原理/机制，事实层面）

- 会议 agent 汇集会议上下文，供其他专门 agent 使用。
- 自助版按 intelligence credits 计量；官网列出识别、反馈、教练、会议摘要等能力。
- 企业 Connected Mode 由 Semos Cloud 配置 Signals Engine，整合 HCM、会议和市场信号，并工程化部署、测试 agent。
- 企业平台列出 SAP SuccessFactors、Workday、Oracle HCM 集成，以及 SSO、SCIM、审计日志等能力。

## 定价 / 商业模式

Semos.ai 自助版：免费档 250 credits/30 天；Pro $39/月、500 credits/30 天；Power $69/月、1000 credits/30 天；可另购 100 credits，官网标价 $15。企业 Connected Mode 按 agent 数量、组织规模、HCM 复杂度与部署范围报价。
