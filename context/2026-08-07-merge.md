## 是做什么的（如实复述，不评价）

Merge 是一个工程师招聘评估 SaaS。候选人不是刷算法题，而是在一个小型真实代码库里 review 一个 PR，留下对 bug、重构和安全风险的 comments。随后 Merge 的 AI agent 会根据候选人的 comments 实时修改代码或回复，模拟一个真实工程师与 reviewer 的来回协作。

评估结束后，Merge 输出候选人在 bug coverage、communication、PR quality、token use efficiency、LLM costs、PR revisions 等方面的报告。

## 解决什么问题（事实层面，不判断值不值得解）

- Maker Harshith Latchupatula 在 PH 自述：团队 5 位 founder 合计做过 250+ interviews，很多面试仍以 Leetcode 或非实际工作技能为主。
- Maker 称在他们各自公司里 PR counts nearly tripled，且许多人一年几乎没有手写代码；团队更重视 code / architecture review，但招聘流程没有同步变化。
- AI-assisted interview 仍常评估 code output；Merge 认为 agent 时代更难的是评审别人或 AI 生成的代码，尤其在自己上下文不足时判断问题和沟通改法。
- 官网首页写“Your engineers are approving more code than ever before. Merge lets you assess for it.”，对应的是工程师从写代码转向审核 AI/他人产出的趋势。

## 怎么做的（技术原理/机制，事实层面）

- Candidate review loop：候选人阅读小型 realistic codebase 和 scoped PR，对 correctness bugs、refactors、vulnerabilities 留评论。
- AI revision：候选人提交 review 后，AI agent 根据 comments 发布新的 PR revision；候选人可继续 review，直到最多 5 revisions 或时间结束。
- Custom assessments：可设置 level（intern/new grad/junior/mid/senior/staff/principal）、specialization（frontend/backend/infrastructure/security/platform 等）和语言范围。
- Reporting：报告连接候选人 comments、code quality、risk detection、revision judgment 和 hiring recommendations。
- Token efficiency：官网与 PH 均强调可看候选人 token use、estimated cost、PR revisions 的效率。

## 关联信息 / 生态

- 与 Leetcode/HackerRank/CodeSignal 类输出型 coding test 不同，Merge 把评估对象放在 code review judgment 和 AI 协作效率上。
- 与普通 take-home 不同，它把候选人与 AI agent 的 review/revision loop 纳入评估，模拟日常 PR 协作。
- 相关产品包括 Triplebyte、HackerRank、CodeSignal、Faltah Interview Simulator，以及 Codex/Claude Code 带来的 agentic coding 工作方式。
