## 是做什么的（如实复述，不评价）

LUCI 是 Mac 与 Windows 桌面应用，可在本机记录线上会议和屏幕活动，将内容整理为可搜索的工作记忆。官方说明包括无需机器人加入会议的记录模式、屏幕记忆，以及通过官方 skills 把相关记忆提供给 Claude、Cursor、Codex 等 agent。

## 解决什么问题（事实层面，不判断值不值得解）

- 会议记录、邮件、代码等分散在不同工具里，之后难以回忆和检索。
- AI 助手每次会话缺乏用户当天工作上下文。
- 线上会议机器人加入会议可能打断原有流程；LUCI 声称本地录制、不让 bot 入会。

## 怎么做的（技术原理/机制，事实层面）

- 桌面应用在 Mac / Windows 捕获用户授权的会议音频与屏幕内容，并在本机建立可搜索记忆。
- 官方称录音、笔记与记忆留在设备上，断网可用；连接 agent 时，仅被 agent 请求的相关片段进入该次对话。
- 支持通过官方 skills 连接 Claude、Cursor、Codex 等工具。底层模型与实现栈未披露。
