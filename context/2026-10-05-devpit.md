## 是做什么的（如实复述，不评价）

devpit 是运行 Claude Code agent 的原生桌面应用：每个项目一个可观察的终端、一块“移动卡片即执行真实工作”的看板、每次 agent 调用的成本显示，以及一个能同时看到所有项目的编排器（读取关联看板，接到卡片后启动会话并回报）。官网称支持 Linux、macOS、Windows，免费开源。

## 解决什么问题（事实层面，不判断值不值得解）

- 同时跑多个 Claude Code 会话时，忘了哪个终端在烧 token（评论用户反馈）

## 怎么做的（技术原理/机制，事实层面）

- 终端 + 看板 + 编排器三件套；本地优先
