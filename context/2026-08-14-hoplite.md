## 是做什么的（如实复述，不评价）

Hoplite 把用户本地的编码 agent 工作流（例如 Claude Code）原样部署到云端，onboarding 时自动迁移用户的 session、MCP 服务器、依赖和各类 CLI，让 agent 在云端"从中断的地方接着做"，不需要用户重新配置环境。用户可以在云端并行跑多个 agent、获得对 agent 产出内容的即时预览，并可以通过 iMessage 从任何地方向 agent 发指令。

## 解决什么问题（事实层面，不判断值不值得解）

- 本地同时跑多个编码 agent 容易导致笔记本崩溃、卡顿
- 多 agent 并行时的 git worktree 管理、端口占用冲突等运维负担
- 需要随时随地（不在电脑前）向 agent 下达指令的场景
- 案例：某企业接入后，Sentry 日志从"基本被忽视"变成"出错时自动生成 PR 主动修复"

## 怎么做的（技术原理/机制，事实层面）

- onboarding 阶段自动迁移用户现有的 session、MCP servers、依赖、CLI 配置到云端
- 云端并行运行多个 agent，避免本地资源瓶颈
- 提供 agent 产出物的即时预览（instant previews）
- 支持通过 iMessage 远程下达 prompt
