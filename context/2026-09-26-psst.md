## 是做什么的(如实复述，不评价)

Psst 是一个跨 iOS / Android / Web 的共享清单与任务协作应用，核心场景是"多人一起维护同一份清单(购物清单、打包清单、家务、跑会清单等)"。它有两块差异化能力：一是基于实时协作的清单本身(链接邀请、角色权限、评论、聊天、活动流、存在指示)，二是收据 OCR + 价格记忆——拍一张超市小票，应用把行项抽取出来并记住每件商品上次在哪儿、多少钱，再以**单位价格**(不是行总价)做对比，避免把"买了 2kg 而非 1kg"误判成涨价。

## 解决什么问题(事实层面，不判断值不值得解)

- 共享购物清单长期停留在"截图往返于备忘录 / 聊天软件"状态，永远落后一版；Psst 把"协作"做成核心机制而不是附加功能
- 超市里 4G / WiFi 差，Psst 提供完整离线模式，恢复连接后再合并
- 跨平台家庭(夫妇 / 室友)用不同系统，Psst 强调 iOS / Android / Web 之间可互通协作
- 普通购物清单不告诉你"上次这个鸡蛋在哪儿买的、多少钱"，Psst 用收据 OCR 累积价格历史
- 现有协作清单(微软 To Do、Todoist)在"共同编辑 + 价格历史"上不重叠

## 怎么做的(技术原理/机制，事实层面)

- 收据扫描走 OCR + 计算机视觉，识别商品名称、价格、单位价格、店铺
- 价格对比在**单位价格**层面做，不在行总价层面做——避免量变引起假阳性涨价告警
- 实时多人同步基于 CRDT 引擎，本地存储 + 后台同步
- "Today view"聚合所有清单中今天到期的条目
- 自然语言快添："milk tomorrow 6pm"被解析成结构化提醒
- 支持编辑者 / 查看者两类角色、条目内联评论、建议条目审批流、存在指示(谁在线)
- 接入：Google Calendar、Outlook(双向同步到期日);Slack(消息转任务、到期提醒);Zapier(连第三方)
- 数据所有权归用户，可随时导出;清单删除为永久删除(非归档)
