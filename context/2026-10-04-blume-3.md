## 是做什么的（如实复述，不评价）

Blume 是 Markdown/MDX 优先的文档框架：把内容放进文件夹，用 `blume` CLI 生成并驱动隐藏的 Astro 项目，得到导航、搜索、主题、OG 图与组件库，无需手写应用样板。需要全控时可 `blume eject`。面向人与 Agent：默认/可配 llms.txt、原始 Markdown URL、JSON API；可选托管 MCP（search_docs / get_page 等）与 Agent skills。Blume 2 把机器可读配置迁到 `agents.*`，Ask AI 改名为 assistant。

## 解决什么问题（事实层面，不判断值不值得解）

- 文档站样板维护成本高，希望零配置出生产级站点
- 文档同时要给人读、给编码 Agent 发现与检索
- 从 Mintlify / Docusaurus 等迁移希望交给 Agent CLI

## 怎么做的（技术原理/机制，事实层面）

- CLI 读 `blume.config.ts`，扫描内容图，生成 `.blume/` Astro 运行时
- AI 表面：llms.txt / llms-full.txt、`.md` 镜像、Copy as Markdown、Open in chat、可选 MCP
- MCP 需服务器输出（静态构建开启会失败提示）
- 支持 OpenAPI/AsyncAPI/GraphQL 参考、多语言、版本冻结、`blume eval` 用 Agent 测文档能否答题
- `npx blume migrate --codex|--claude` 迁移既有文档站
