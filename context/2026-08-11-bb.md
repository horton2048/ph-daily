## 是做什么的（如实复述，不评价）

bb 是一款**本地优先的 agent 编排 IDE**，定位为"loop-driven development"（循环驱动开发）。它本身不是模型，而是统一调度用户已有的编码 agent CLI（Claude Code、Codex、OpenCode、Cursor、Piopencode、Grok Build 等 ACP 兼容 agent），让这些 agent 在同一个 GUI 里并行跑、互相协作、并可被外部程序（shell 脚本、cron、聊天机器人）程序化驱动。

差异化卖点在于**自指/可自改**：用户用一句话 prompt 即可让 bb 给自己加功能（例如加任务追踪面板、加 `bb tasks` 命令、加一个让所有 agent 学会使用该功能的 skill）。官方原话："almost anything in bb can also be changed or extended with a prompt"。核心功能如 Workflows、side chat、crons、inline previews、remote access 均以**插件**形式实现，且插件与用户自建扩展用的是同一套工具链——"the IDE that builds itself"即指此。

运行方式：每条工作在一个独立 git worktree（"bbWorktree"）里执行；agent 对代码库有 Full Access；同一套 CLI 既能被人用，也能被外部 bot/脚本/cron 调起，从而实现"一个 agent 启动另一个 agent"。

## 解决什么问题（事实层面，不判断值不值得解）

- 多编码 agent（Claude Code、Codex、Cursor 等）各自孤立运行，缺一个统一 GUI 来并行编排、互相交接线程。
- 传统 IDE 不能自改：想加一个面板或命令要改源码发版；bb 把"扩展 IDE 本身"变成一句 prompt 的事。
- 外部触发（Telegram/Signal/Slack bot、cron、CI）难以驱动本地 agent 工作流；bb 把 CLI/HTTP API 设为一等公民，可被任意程序驱动并在线程面板里等待。
- 已有 agent 订阅无法跨工具复用：bb 不收费、不重新计费，直接用用户已认证的 provider CLI。

## 怎么做的（技术原理/机制，事实层面）

- **架构**：pnpm workspace + Turborepo 单仓库，包含 `apps`/`packages`/`plugins`/`scripts`/`tests`/`docs`。运行组件含 Vite 应用、独立 dev server、host daemon、Electron 桌面 shell。app 热重载，server 与 host daemon 不热重载。开发态数据落在 `~/.bb-dev/`。
- **agent 编排**：通过 ACP（Agent Client Protocol）兼容协议接入多个 provider CLI；agent 各自在独立线程/worktree 中运行，可实时跟踪、随时接管或交给另一个 agent。
- **自改机制**：用户 prompt → bb 调用底层 agent → 生成插件代码 + 对应 skill（skill 教会所有 agent 如何使用新功能）。社区已用此机制做出 tiling systems、自动 code review、markdown 编辑器，甚至"在 bb 里跑的 DAW"。
- **安装**：macOS Apple Silicon 一键桌面安装（无需终端）；也可 `npx bb-app@latest` 后访问 `http://localhost:38886`；nightly 通道 `npx bb-app@nightly`；Intel Mac/Linux 走 npx；Windows 需 WSL2。
- **遥测**：生产构建发送匿名遥测（app 启动、线程数、消息数，仅一个随机 install ID）；源码/开发构建不发；`BB_TELEMETRY=false` 可关闭。

## 定价 / 商业模式

- bb 本体**完全免费、MIT 许可、端到端开源**（github.com/get-bb/bb）。
- 不收订阅、不收 API 加价：用户**用自己已有的 provider 订阅**（Claude Code、Codex、Cursor 等），账单由 provider 出，bb 不经手计费。
- 无明确付费版/企业版/托管版（截至归档日）。盈利路径未披露。

## 关联信息 / 生态

- **支持 provider/agent**（官网列出）：Claude Code、OpenAI Codex、Cursor、Pi (Piopencode)、opencode (OpenCode)、Grok Build、oh-my-pi (omp)、Hermes Agent，"+5 more"。模型示例：Claude Opus 4.8 1M。
- **插件生态**：GitHub 集成、agent memory、scheduled jobs、remote access、Workflows、side chat、crons、inline previews 均为官方插件；社区插件含 tiling、code review、markdown 编辑器、DAW 等。
- **竞品定位**：与 Cursor / Windsurf / Zed 同属 AI IDE，但 bb 不自带模型、走"编排任意 agent CLI"路线，更接近 Cline/OpenHands 的 agent-agnostic 思路；自指能力（用 prompt 改 IDE 本身）是其差异化主张。
- **社区**：Discord、Newsletter、Dashboard；GitHub 仓库 ~1.6k stars / 155 forks（归档日快照）。
