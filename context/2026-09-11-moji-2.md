## 是做什么的（如实复述，不评价）

一个**桌面 Markdown 阅读 + 编辑器**，核心定位是"打开 Markdown 跟打开 PDF 一样简单"——双击 `.md` 文件直接进入阅读视图，没有项目树、没有插件面板、没有 IDE 噪音。

形态上是跨平台 Electron 应用（Win/Mac/Linux 都有原生安装包），同时支持阅读和编辑：
- **阅读模式**：sanitized Markdown 渲染 + outline 大纲导航 + scroll-spy + 暗色/亮色主题
- **编辑模式**：CodeMirror 6，支持 Markdown 快捷输入、行号、撤销历史、查找替换
- **导出**：HTML / PDF（A4/Letter/Legal，横竖向）/ PNG
- **特色渲染**：Mermaid 图（流程图/时序/Gantt/类图/ER/状态/旅程）、KaTeX 数学公式、表格/任务列表/脚注/定义列表/上下标/高亮/emoji shortcode/语法高亮代码块

## 解决什么问题（事实层面，不判断值不值得解）

- **"为读一个 .md 启动整个 IDE 太重"**（创始人原话）：VS Code、JetBrains 系列、Obsidian 对"只是想看一眼 README"这个动作来说开销过大
- **PDF 般的"双击即读"在 Markdown 上长期缺位**：现有 Markdown 工具多偏编辑器向（Typora/Mark Text/Zettlr）或笔记库向（Obsidian），纯阅读器少且多平台覆盖差
- **离线/本地阅读大量 Markdown 文档库**：单实例 + 流式 UTF-8 读取 + >20MB block virtualization + bounded-concurrency 多开，针对本地文档集合
- **作者写作场景需要所见即所得的导出**：HTML/PDF/PNG 三种导出，且 Mermaid 在导出中以自包含 SVG 嵌入（导出的 PDF 离线可看 Mermaid）
- **多语言用户群**：UI 提供 15 种语言（含简/繁中文、日/俄/阿拉伯/印地等），跟随系统语言首次启动，用户选择持久化

## 怎么做的（技术原理/机制，事实层面）

- **桌面安全姿态**（比一般 Electron 工具更严格）：
  - `nodeIntegration: false`
  - sandboxed renderer
  - `contextIsolation` 开启
  - preload.ts 通过 `contextBridge` 暴露受限 API
- **大文档工程化**（这是它最有差异化的工程部分）：
  - 文档流式分块读取（chunked UTF-8 streaming）
  - >20MB 文档走 block virtualization
  - bounded-concurrency 批量打开（带进度条 + 可取消）
  - untitled document 草稿恢复
- **本地图片协议**：自定义 `moji-asset://` 协议，路径受权 + LRU 缓存，不允许任意文件访问
- **Markdown/Mermaid 渲染走 Web Worker**：渲染管线不阻塞编辑器
- **更新机制**：Windows NSIS 和 Linux AppImage 用 `electron-updater`（带自动更新检查）；macOS 因未签名无自动更新（DMG + ZIP 手动）
- **Mermaid 图表查看器**：独立的 modal，10%–1000% 缩放 + 自由拖拽 + 缩略图导航 + 单图 PNG 导出

## 定价 / 商业模式

- **完全免费** · MIT 协议 · 无付费 tier · 无 SaaS · 无云同步 · 无遥测
- 三平台均通过 GitHub Releases 分发：
  - Windows：NSIS 安装包（自动更新）
  - macOS：Universal DMG（不自动更新，因未签名）
  - Linux：AppImage（自动更新）+ DEB
- **macOS 首次运行限制**：未通过 Apple 公证（无付费 Developer 账号），需要 System Settings → Privacy & Security → Open Anyway，或 `xattr -dr com.apple.quarantine /Applications/Moji.app`（macOS 15+ 已取消 Ctrl-click → Open 这个绕过路径）
- **版本节奏**：release 流程文档化（`package.json` + `package-lock.json` 同步 bump → verify → 分平台 dist → 推 tag → 上传 `latest.yml`），但未声明 CI，**手动发布**；README 明确"macOS 是次要平台，不要因 DMG 问题阻塞发布"
