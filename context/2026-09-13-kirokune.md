## 是做什么的（如实复述，不评价）

一款 iPhone 独占的"工作 / 个人事件记录"应用。用户在 App 内创建 **Case（案件/事件）**，往里追加 **文字笔记、语音录音、照片**，所有条目按时间线（Timeline）展示。支持把 Apple Messages / Meta Messenger / Instagram 导出的聊天记录文件本地解析后导入对应 Case，用于事后整理。导出由用户手动触发——免费版用户可以在 App 内把单个 Case 导出 PDF（仅 Plus 付费功能之一），用于交给 HR、律师或心理咨询等第三方。

## 解决什么问题（事实层面，不判断值不值得解）

- 场景：工作场所中的言语骚扰（power harassment / moral harassment）、职场冲突、个人敏感事件需要"事后留痕"
- 痛点 1：现有笔记 App 要么强制注册账号，要么同步上云，对"敏感场景留痕"不够友好
- 痛点 2：当时情绪上来想立刻记，但分类、命名、判定"算不算事件"反而把记录摩擦变大
- 痛点 3：录音常被打断（息屏 / 切 App / 来电），错过关键几秒
- 目标场景：日本 + 英文市场的职场 + 个人敏感事件当事人；据 PH 描述面向"power harassment / moral harassment / domestic violence" 等情境

## 怎么做的（技术原理/机制，事实层面）

- **离线优先 / 无账号 / 无云同步**：所有记录仅存于本机 iPhone；除非用户主动导出，不会离开设备
- **NSFileProtectionComplete**：iOS 文件保护级别设为 Complete，加密内容与设备锁绑定
- **Face ID / 设备密码锁**：进入 App 需解锁；App 切换器中内容自动隐藏
- **录音可在锁屏 / 切后台时继续**：录音控件出现在锁屏界面和 Dynamic Island 上，避免被切后台打断
- **三层记录结构**：
  1. 原始音/文/图（不可覆写）
  2. 本地生成的转写文本（可编辑）
  3. 按时间顺序整理的草稿（仅作参考）
- **聊天记录导入**：解析用户从 iMessage / Messenger / Instagram 导出的聊天文件（不连接 API、不要求提供账号）
- **不做判定**：App 与官网明确不使用 "certification / diagnosis / legally valid / counts as evidence" 等字眼——只做"记录 + 组织"
- 失败/误处理：App FAQ 提示删除后无备份则无法恢复（除非事先导出）；录制受当地录音法规约束，用户自负责任

## 定价 / 商业模式

- **免费版**
  - 1 个 Case，无限条记录（笔记 / 录音 / 照片）
  - 包含一个免费的事件记录模板（来自官网 guide 页面，可不下载 App 直接使用，且不要求留邮箱）
- **Kirokune Plus（付费）**
  - 解锁多 Case
  - 解锁详细回顾工具
  - 解锁 PDF 导出
  - 去广告
  - 付费形式：月订阅 / 年订阅 / 一次性买断（具体金额官网未直接披露）
