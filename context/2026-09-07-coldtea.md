## 是做什么的（如实复述，不评价）

PR Lens 把拉取请求中的代码变化转换为架构图和数据流图，并把图直接放进 GitHub PR。它既可作为托管 GitHub App 自动维护一条随 push 更新的评论，也可通过 GitHub Action、CLI 或编码 Agent Skill 在用户自己的环境中运行。

## 解决什么问题（事实层面，不判断值不值得解）

- AI 编码工具可以一次生成跨很多文件的变更，审查者仍要从逐行 diff 还原整体结构和影响范围。
- PR 的文字摘要通常难以直观表达组件新增、修改、删除以及数据经过的顺序。
- 团队希望在 GitHub 内完成首轮理解，而不是切到独立仪表盘。

## 怎么做的（技术原理/机制，事实层面）

- 模型先把 diff 分析成强类型 graph document；schema、renderer、CLI、Action 和 Agent Skill 分包维护。
- 自定义渲染器把图文档确定性转换为浅色/深色 SVG；文字测量使用内置表，降低不同 CI 字体环境导致的输出差异。
- 动效写入 SVG 的 `animateMotion`，输出不依赖 JavaScript，可在 GitHub 会移除脚本的评论环境中播放。
- 架构、数据流等 lens 共用一份文档；新增、修改、删除分别用绿色、琥珀色和红色表达。
- App 托管模式不需要用户提供模型密钥；Action/CLI 可使用 Gemini、OpenAI 或 OpenAI-compatible 接口。Agent Skill 也可复用当前编码 Agent 已有的模型理解结果。
- 命名错误、排除项、泳道固定和分组可写入 `.github/pr-lens.yml`，避免直接改下一次会被覆盖的生成 SVG。

## 定价 / 商业模式

- 代码仓库以 MIT 协议开源。
- 官网明确写明 GitHub App 对开源仓库免费；私有仓库定价未公开。
- GitHub Action、CLI 和 Agent Skill 本身可自行运行，但分析步骤需要用户承担所选模型供应商的调用成本。

## 关联信息 / 生态

- 与 CodeRabbit 等文字型 AI code review 工具解决相邻问题：PR Lens 输出结构图，而不是逐行缺陷评论。
- Agent Skill 可通过 `npx skills add coldteadotai/pr-lens` 安装，文档列出 Claude Code、Codex、Gemini CLI、Cursor、OpenCode 和 Copilot 等使用场景。
- CLI 要求 Node 20.11+；仓库开发流程使用 pnpm 10。
