## 是做什么的（如实复述，不评价）

一个把 AI agent 从本地笔记本搬到云端持续运行的平台。当前 AI 工作流（如 Claude
Code）运行在用户本地机器上，合上电脑即停止。Omni 让 agent 在云端持续运行，
关机后仍能 7×24 自动执行工作流。支持 Slack 集成，agent 可通过 Slack 交互。

## 解决什么问题（事实层面，不判断值不值得解）

- AI agent 依赖本地机器运行，合上笔记本即停，无法持续工作
- 需要人工"保姆式"看护 agent，无法真正自动化
- agent 只服务单人，无法共享给团队

## 怎么做的（技术原理/机制，事实层面）

- 将本地 agent 工作流部署到云端运行环境
- 支持 Slack 集成，agent 通过 Slack 通道与用户交互
- 具体云端架构、容器/编排方式未查到
