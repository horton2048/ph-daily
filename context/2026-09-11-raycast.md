## 是做什么的（如实复述，不评价）

Mac 启动器起家，定位是"键盘优先的可扩展生产力中枢"。核心动作是按一个全局快捷键呼出 Root Search，输入文字后回车执行命令（打开应用 / 跑脚本 / 搜文件 / 调扩展 / 问 AI / 触发快捷链接）。

2.0 把范围扩到：内置 Dictation、Notes、Clipboard History、Window Management、Translator、Calculator、Flight Tracker、Focus、Snippets、Quicklinks；并通过 AI Agent / AI Chat / Quick AI 把"问 AI"接成系统级动作，能跨已安装的 Mac Skills 自动调用。

## 解决什么问题（事实层面，不判断值不值得解）

- **Spotlight 不好用**：Mac 自带的 Spotlight 不可定制、不支持跨平台、无法跑工作流；Raycast 自建索引把"应用/命令/文件/快捷链接/AI"统一到一个 Root Search
- **Mac 启动器选 Alfred 不够现代**：Alfred 是 2009 年的产品，工作流语法老；Raycast 用现代扩展 SDK（TypeScript/React UI、热重载、Node 运行时）+ Store 分发
- **AI 不是独立 App 而是 OS 层动作**：传统 ChatGPT/Claude App 需要切换窗口、复制粘贴上下文；Raycast 把 AI 接到 Quick AI（任何 app 内一键呼出）+ AI Chat（长会话）+ AI Agent（自动跨扩展执行）
- **开发者工具的 CLI 思维 + GUI 体验**：传统 Alfred Workflow 用 AppleScript/shell 拼接，扩展难写难分发；Raycast SDK 用 TypeScript + React，提供官方 UI 组件，扩展可直接发布到 Store
- **跨平台碎片**：开发者要在 Mac/Windows/iOS 间保持同一快捷键习惯，2.0 把同一份 UI 代码（React）跑在三个平台上

## 怎么做的（技术原理/机制，事实层面）

### 跨平台四 runtime 架构（代号 X-Ray）

- **Native shell（原生壳）**：macOS 用 Swift + AppKit，Windows 用 C# + .NET 8 + WPF。负责全局快捷键、剪贴板、辅助 API、窗口管理、不抢焦点的悬浮面板——这些都需要底层原生控制
- **Web frontend**：React + TypeScript，一份代码库，按窗口拆入口（Launcher / AI Chat / Notes / Settings）。macOS 用 WKWebView，Windows 用 WebView2
- **Node backend**：单一长生命周期 Node 进程，拥有业务逻辑、数据库访问、扩展运行时、共享服务
- **Rust core**：性能或跨平台共享关键处使用——共享数据层（iOS 也用）、云同步 schema、文件索引器

四者通过平台消息处理器和 stdio 传输连接，接口在单点声明，自动生成四端的类型化客户端，编译期保证类型一致。

### 为何不选 Electron / Tauri

- **Electron**：Mac 上要捆绑 Chromium 而系统 WebKit 已经在，且 Electron 对全局快捷键、剪贴板、辅助 API、悬浮面板的低层控制不够细
- **Tauri**：原生控制力不足，且项目当时太年轻，不敢拿整个公司赌

### 文件索引器（自研，Rust）

- 独立进程，Rust 实现，直接扫文件系统
- 通过文件系统事件保持索引更新
- **Windows 专用**：NTFS 扫描器直接读 Master File Table（MFT），几秒内索引完整个盘，而不是几分钟
- 取代了 v1 对 Spotlight metadata 的依赖——Spotlight 不能跨平台、不能定制
- 跑在后台，可预测内存占用，无 GC 暂停

### WebKit 工程化的若干 hack

- **节流问题**：禁用 WebKit 的遮挡检测，把窗口强制前置但视觉隐藏（alphaValue = 0），用 requestAnimationFrame 触发渲染后再显示
- **被遮挡帧渲染**：WKWebView 始终保持展开尺寸，内容在窗口扩展前已渲染好
- **窗口缩放**：覆盖 NSWindow.setFrame，把动画调用换成隐式 Core Animation，缩放过程 WebView 持续渲染
- **打开时的闪烁**：用 _doAfterNextPresentationUpdate 确保 WebView 画完再让窗口可见
- **Emoji 渲染**：启动时预热 emoji 字体，避免逐字形走字体链 fallback
- **Feature flags**：建基础设施在运行时切换 WebKit Feature Flags——解锁 60 FPS 上限、启用 requestIdleCallback

### macOS 设计规约

- 交互控件不加 cursor: pointer
- 大多数控件不加 hover 高亮（贴合 macOS 原生）
- Settings 用独立原生窗口打开，不是 modal 或侧栏
- Popovers 和 tooltips 用原生窗口渲染，可以超出 WebView 边界
- **macOS Tahoe：采用 Apple 的 Liquid Glass 材质**

### 性能数字（来自官方工程博客）

| 组件 | v1 | v2 |
|---|---|---|
| 典型占用 | 200–300 MB | 350–450 MB |

v2 拆解（主窗口隐藏时）：
- WebView（WebContent）：~120–200 MB
- Node.js backend：~150–200 MB
- Native app（Swift 壳）：~40 MB
- WebKit GPU process：~18 MB
- WebKit Networking：~12 MB

基线参考：空 WebView ~50 MB；裸 Node.js 进程 ~12 MB。

## 2.0 重大新功能（按官方 manual 整理）

### Fresh Design（全新设计）

- 为 macOS Tahoe 的 Liquid Glass 重新设计
- 新增 compact mode（紧凑模式），界面精简到必要元素
- Emoji & Symbols 和 Screenshots 支持通过网格调整列数

### Search Files and Settings（文件和设置搜索）

- Root Search 输入文件名/文件夹名直接出 File Search 结果，不再单独切命令
- File Search 用新索引引擎，速度更快、过滤器更多
- Settings 有独立搜索，覆盖每个扩展、命令、设置项

### Even More Shortcuts（更灵活的快捷键）

- Hotkey 录音器更快更可靠，带键盘感知
- 支持 fn 单键做 hotkey
- 左右修饰键可独立绑定
- 在启动器的 Action Panel 内可直接设 hotkey

### Ask AI, Anywhere（随处问 AI）

- Quick AI 出现在 Root Search，能回答问题
- Quick AI 视觉对齐 AI Chat
- Quick AI 可设为 fallback command，把非命令查询路由到 AI
- AI Chat 支持从任意消息分支出新对话，保留原线程
- 接近上下文上限时自动总结早期对话，继续推进
- AI Extensions 自动按需加载
- Screen Awareness 自动附带当前聚焦窗口、选区、截图
- 新聊天侧栏：Projects（共享指令、自动归档、消息通知）

### A More Personal AI（更个人化的 AI）

- **Profile**：用户填入职业/兴趣/价值观/写作偏好等个人信息
- **Memory**：对话中自动学到的信息
- **Agents**：替代 Presets，作为可复用配置
- **Skills**：为重复任务提供指令和知识

### Talk Instead of Typing（语音替代输入）

- Dictation 在当前 app 出干净格式化文本，处理填充词和标点
- 自动检测口语语言或用配置的默认语言
- Auto Styling 按上下文调整语气（Mail 里写邮件 vs Slack 里发消息）
- Styles 允许为每个 app 或网站设自定义 prompt

### Projects and Automations（项目与自动化，2026-09 新定价同捆发布）

- **Automations**：定时让 agent 后台跑任务（如分拣邮件、看 PR、更新 memory）
- **Projects**：分组对话，可有独立 memory 和工作目录（如 Obsidian vault、发票文件夹）

### 其他 Quality-of-Life 改进

- Snippets / Quicklinks / AI Commands 支持 Tags
- Clipboard History 保留所有原始格式（改善向 Slack/Notion 粘贴体验）
- Translator 支持自定义常用语对命令
- Window Management 新增 Toggle Grid Overlay 用于可视化定位
- Settings 界面重新设计，更一致

### 系统需求

- **macOS Tahoe**（macOS 26）
- **Apple Silicon**（不支持 Intel Mac）
