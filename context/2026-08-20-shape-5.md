## 是做什么的（如实复述，不评价）

Shape 是一款**智能体 IDE**，把设计、编码、Git、AI 聊天集成到同一个桌面应用里。它面向"既要做设计也要写代码"的人群——传统 IDE（Cursor/Windsurf）偏代码，Figma 偏设计，Shape 试图做两者的融合。

tagline 是 "agentic IDE for designers and programmers"——核心差异化在于"智能体"+"设计 + 编程双栖"。

## 解决什么问题（事实层面，不判断值不值得解）

- 设计↔开发的传统割裂：设计师在 Figma 做稿，开发在 IDE 里写代码；中间的"设计稿 → 代码"转化是大量损耗
- 现有 AI IDE（Cursor / Windsurf / Copilot）偏代码，设计师用不顺手
- Figma 自身在加代码能力（Figma Make），但 Figma 是设计工具不是 IDE
- "智能体"模式：让 AI 自动在设计稿和代码之间穿梭

## 怎么做的（技术原理/机制，事实层面）

- 集成：设计视图 + 代码视图 + Git + AI 聊天四合一
- 智能体：AI agent 在设计稿和代码之间自动转换和生成
- 形态：桌面应用（PH 标签 Design Tools · Developer Tools · Artificial Intelligence）
