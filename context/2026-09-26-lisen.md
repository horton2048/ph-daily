## 是做什么的（如实复述，不评价）

Lisen 是一款 Chrome 浏览器扩展，点一下就能把当前网页（文章、博客、newsletter、技术文档、Substack、Medium 等）用 TTS 念出来。底层用的是用户自己 Cartesia 账号里的声音——不是 Lisen 自带音色，而是用 Cartesia API key 调用用户库里已有的任何声音（包括克隆声或自设计声）。播放器是一个浮窗，会高亮当前段落、跟读时把正在念的字标出来；支持流式即时起播，也支持"先把整篇文章预渲染完"再播（此时会有精确总时长和 scrub bar），并能把整篇文章导成 WAV（带字级时间戳，可二次做跟读素材）。

## 解决什么问题（事实层面，不判断值不值得解）

- 想"听"长文章 / newsletter / Substack / Medium，而不想看屏幕
- 已经有 Cartesia 订阅，希望把这套音色能力直接用在网页浏览场景，不想再买一个 read-aloud 扩展订阅
- 需要把网页内容带走（比如塞进别的音频播放列表、做离线跟读素材），因此导 WAV + 字级时间戳是直接对应的能力

## 怎么做的（技术原理/机制，事实层面）

- 形态：Manifest V3 Chrome 扩展，注入一个浮层播放器；点击播放时把页面文本通过 Cartesia API 推到 Cartesia 服务
- 模型层：Cartesia Sonic 系列（Cartesia 是底层 TTS 提供方，Lisen 不自研声学模型）
- 播放模式两种：① 流式（按段请求 Sonic，~90ms time-to-first-audio 起播）② 全文预渲染（拿完整时间戳，支持 scrub bar）
- 导出能力：把整篇文章渲染后下成 WAV，时间戳按词保留，可作跟读
- 隐私设计：无 Lisen 中间服务器；API key 与设置存在 Chrome 本地；只有按播放那一刻页面文本才出域到 Cartesia；声明无 analytics/telemetry
- 错误/失败处理：未查到显式降级策略文档（流式 vs 全文渲染本身可视为两种模式互为备份）

## 定价 / 商业模式

Lisen 本身**免费、无独立订阅、无广告**——它的商业模式不是收用户钱，而是"搭在 Cartesia 之上"：用户必须自己已有 Cartesia 账号、填 API key，按 Cartesia 的字符计费付钱给 Cartesia。Cartesia 2026 公开价位（用于上下文，不是 Lisen 收费）：

| Cartesia 套餐 | 月费（年付 / 月付） | 信用额度 | 备注 |
|---|---|---|---|
| Free | $0 | 20K credits | 非商用 |
| Pro | $4 / $5 | 100K credits | 商用授权最低门槛 |
| Startup | $39 / $49 | 1.25M | 团队工作区 |
| Scale | $239 / $299 | 8M | 高并发、优先支持 |

> 计费：TTS 1 credit/字符（含空格标点）；STT 1 credit/秒。Sonic-3 实测中位延迟约 166–190ms（含网络），宣称 ~90ms 模型端 TTFA。
