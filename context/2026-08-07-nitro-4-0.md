## 是做什么的（如实复述，不评价）

Nitro 4.0 是 Alconost 推出的人工翻译平台更新，面向 AI agents 和自动化工作流。它让 agent 不需要账号、API key 或人工登录流程，就能发起小段文本翻译订单、完成付款、轮询或通过 API 获取人工译者的结果。

它不是机器翻译模型，而是把专业 native translators 接到 agent 可调用的支付与订单流程里，适合广告、应用更新、邮件序列等短文本。

## 解决什么问题（事实层面，不判断值不值得解）

- AI agent 可以生成和改写多语言内容，但在需要人工译者把关的场景，传统翻译平台通常要求账号、余额、人工下单或 API key 配置。
- 对短文本来说，企业本地化流程可能过重；Nitro 强调无订阅、无最低订单、按需下单。
- 官方称支持 80+ languages，适合广告、app updates、email sequences 等小文本。
- 官方称 96% orders within 24h；maker 也提到平均 2–24h，历史上约 60% 在 2h 内完成。这是官方/团队口径，未查到第三方验证。

## 怎么做的（技术原理/机制，事实层面）

- Agent 调用时提交文本与目标语言，服务返回 Payment Required challenge。
- Agent 使用 MPP machine payments protocol 提交 payment proof 后重试请求，平台创建翻译订单。
- 订单完成前可 polling；完成后通过 access token/API 取回译文。
- 译文由专业 native translators 完成；具体译者审核、质检、隐私处理、退款争议流程需查完整条款。

## 定价 / 商业模式

公开资料显示 Nitro 支持 pay-as-you-go / balance top-up，信用卡经 2Checkout 等方式支付；没有查到 4.0 launch 对 agent 调用的统一公开价目表。商业模式本质是按翻译订单收费，平台从人工译者交付的本地化服务中收费。

## 关联信息 / 生态

- Nitro 4.0 连接的是 AI agent 与 human-in-the-loop 服务：agent 负责发起和支付，人工译者负责翻译结果。
- 与 DeepL 等机器翻译不同，它强调 human translation；与传统 LSP 不同，它强调 agent-friendly machine payment 和轻量订单。
- 相关产品/方向包括 Gengo、Smartling、Lokalise、Transifex、DeepL API、Alconost Localization。
