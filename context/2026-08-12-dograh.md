## 是做什么的（如实复述，不评价）

Dograh 是一个开源、可自托管的语音 AI agent 平台，用来搭建预约、外呼、客服、催收等场景的语音机器人，定位为 VAPI/Retell 的开源替代品。提供可视化流程编排器（不用写胶水代码）、70+ 语言实时语音转语音（支持通话中切换语言）、带人工暖转接的电话能力、通话录音自动 QA、免费 REST API，以及原生 MCP 支持（可接 Claude Code）。一条命令即可本地部署。

## 解决什么问题（事实层面，不判断值不值得解）

- 商用语音 AI 平台（VAPI 等）闭源、按分钟计费、有供应商锁定；Dograh 开源全部代码，BSD-2 协议，"nothing held back"。
- 需要合规敏感行业（fintech、healthtech、defense）自托管部署、数据不出域的场景。

## 怎么做的（技术原理/机制，事实层面）

- 底层用 Pipecat 做语音管线，PostHog 做产品分析，ElevenLabs 做 TTS/语音能力。
- 一条命令 Docker Compose 自托管部署，用户自带模型 API key（BYOK）或跑本地模型完全离线。
- MCP 原生集成，可被 Claude Code 等 agent 调用。
