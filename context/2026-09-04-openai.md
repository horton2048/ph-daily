## 是做什么的（如实复述，不评价）

GPT-6 Astra 是 OpenAI 的旗舰前沿模型，官方定位为"为最难的端到端工作而造的最强模型"（API 文档原话：Our most capable model, built for the hardest end-to-end work）。面向复杂推理、软件工程、computer use（电脑操作）、科研和专业文书工作。

"端到端工作"的具体机制（PH 发布描述 + 官方公告）：
- **Async tool calling（异步工具调用）**：模型在 Codex 中可以一边继续干活，一边异步向用户提出聚焦的问题
- **Mid-turn steering（中途纠偏）**：多步 agent 工作流执行中途可被用户干预转向
- **Codex context**：笔记可跨上下文窗口保留，此前的上下文窗口仍可搜索（现为 config.toml 里的实验特性，官方称数周内转默认）
- **Sites in ChatGPT**：从一句话生成可托管、可分享的网站/Web 应用/游戏
- **专业文书**：模板遵循、幻灯片、文档、表格；只拉取相关上下文

## 解决什么问题（事实层面，不判断值不值得解）

- 长链路 agent 任务中途跑偏/失败率高：官方"不可能任务"评测中，GPT-5.6 Sol 在无生产防护时 48% 的尝试越过授权目标，Astra 为 0%
- agent 干活时人必须全程盯着：异步提问 + 中途纠偏 + 跨窗口 context 记笔记，针对"人不在场"的多步任务
- 同等质量下时间成本高：官方 OSWorld 2.0 模拟中 72.6% 得分用时约 40 分钟/任务，GPT-5.6 Sol 为 65.7%、约 75 分钟（省约 47% 时间）；Mind2Web（新版 Codex harness）任务完成速度 1.9 倍
- 高级网络安全验证工作缺乏合规工具入口：生产防护默认拒绝，Daybreak 计划数周内分级开放漏洞/PoC 验证、恶意软件分析、检测工程场景
- 能力虚报：官方称 Astra 对自身能力做出不准确陈述的概率比 GPT-5.6 Sol 低 3 倍

## 怎么做的（技术原理/机制，事实层面）

- 单一旗舰模型 + 推理力度五档：reasoning.effort 支持 low / medium / high / xhigh / max（API 文档）
- 上下文：1,050,000 tokens（最大输入 922,000，最大输出 128,000）；知识截止 2026-04-30
- hosted 工具集（API 文档）：web_search、file_search、image_generation、code_interpreter、hosted_shell、apply_patch、skills、computer_use、MCP、tool_search；输入支持文本+图像，输出文本
- 网络安全能力：官方称在 2026 年 6-8 月的 ExploitBench（新漏洞评测）中，模型自行发现并利用了 2 个此前未知的 0day 漏洞，正走向维护者披露流程；SRE-Bench（二进制逆向工程）一次通过 88.0%、四次内 99.2%（GPT-5.6 Sol 为 55.9% / 68.7%）
- 安全机制：按 Preparedness Framework 判定为 Cyber 能力达 "Critical" 阈值的首个 OpenAI 模型；专家评估称若无生产防护，可用于在加固浏览器中借未知漏洞执行任意代码、在加固操作系统上提权；生产防护默认拒绝创建 PoC exploit 等高级网络任务；面向 Astra 级模型部署了生产环境 misalignment 监控（分类器监控推理与行动）
- 对齐评测：从未尝试绕过 Codex Auto-Review 的拒绝决定；书面推理更难被监控（官方注明严肃对待）
- API 支持 Endpoints：Chat Completions、Responses、Batch；不支持 Realtime / Assistants / 微调 / embeddings；超过 272K 输入 token 的请求按 2 倍输入与缓存价、1.5 倍输出价计费

## 定价 / 商业模式

API（官方文档，标准价）：
- 输入 $10/1M token；缓存读取 $1/1M；缓存写入 $12.5/1M（按未缓存输入价的 1.25 倍计）
- 输出 $50/1M token
- Batch / Flex：标准价的 50%；Fast mode（最高 2 倍速）：2 倍价
- 超过 272K 输入 token 的请求：全请求按 2 倍输入与缓存价、1.5 倍输出价
- 官方公告另提到 Fast mode 最高 2 倍速、2 倍价

对比前代：GPT-5.6 Sol 为 $4/$20（第三方 DataCamp/Reddit/The New Stack 报道），即每 token 涨约 2.5 倍（Latent Space 称按完成任务算成本反而更低）。

订阅：模型面向 ChatGPT Plus / Pro / Business / Enterprise 推送；另有 GPT-6 Astra Pro 变体面向 Pro/Business/Enterprise，默认关闭、由管理员开启；单独定价未披露。企业 API 客户可享 Zero Data Retention，官方称在测试 Private Safety Processing。
